Zuken E3.series คืออะไร?

E3.series เป็นซอฟต์แวร์ของ Zuken สำหรับออกแบบระบบไฟฟ้า (Electrical Schematic), ระบบสายไฟ/สายเคเบิล (Wiring & Cable Harness), และแผงควบคุม (Panel Layout) ใช้กันแพร่หลายในอุตสาหกรรมยานยนต์ เครื่องจักรอุตสาหกรรม และระบบราง เชื่อมโยงข้อมูล Symbol กับฐานข้อมูลชิ้นส่วน (Component Database) เพื่อให้ BOM, Wire List และรายงานต่างๆ ตรงกับแบบจริงเสมอ

ใช้เว็บนี้ยังไง

  1. เริ่มที่เมนู Basic ถ้ายังไม่เคยเปิดโปรแกรมมาก่อน
  2. ไปที่ Advanced เมื่อเข้าใจ Object พื้นฐานแล้ว และอยากบริหาร Library/Harness แบบมืออาชีพ
  3. ดู Example File เพื่อฝึกทำตามวงจรจริงทีละขั้นตอน
