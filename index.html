เรียนรู้ Zuken E³.series

ชุดสอน Step by Step บน E³.series ภาษาไทย

ลงมือทำทีละบท ตั้งแต่รู้จักหน้าจอ, เขียนวงจรไฟฟ้าด้วย E³.schematic, วางอุปกรณ์ในตู้ด้วย E³.panel ไปจนถึงสร้าง Symbol, Component และ Model เองใน Database Editor — ทุกบทมีภาพหน้าจอจริงพร้อมเลขกำกับ บนโปรเจกต์ตัวอย่าง Cooling water pump ที่มากับโปรแกรม

แบบทดสอบก่อนเรียน

แบบทดสอบ 20 ข้อ และความคาดหวังต่อการเรียน ประมาณ 15 นาที — ใช้เทียบคะแนนกับหลังเรียน

Step by Step 00–04

ทุกบทใช้สำเนาของโปรเจกต์ตัวอย่าง Cooling water pump.e3s ที่มากับโปรแกรม (คัดลอกมาไว้ในโฟลเดอร์ของตัวเองก่อนเปิด) — บท 02 ทำต่อจากผลของบท 01 ส่วนบท 03–04 ทำใน Database Editor บนสำเนาฐานข้อมูล

00

หน้าจอและพื้นฐาน

เปิดโปรเจกต์ .e3s หน้าจอ 5 ส่วน ค้นหา Component, Settings / Grid, เมาส์และคีย์ลัด แล้ววางอุปกรณ์ตัวแรก — 13 ขั้น
01

วงจรไฟฟ้า E³.schematic

เพิ่ม Sheet และหัวกระดาษจาก Translation Table, Device Properties, Copy / Paste วงจร, Search / Jump, Terminal Plan และส่งออก PDF — 11 ขั้น
02

ออกแบบตู้ E³.panel

วาง -Q6 จากแท็บ Not Placed ลงราง, เพิ่ม Cable Duct / Mount TS 35 mm, Panel Autoconnect, ดูตู้ 3D และ Wiring list — 10 ขั้น
03

สร้าง Symbol และ Component

Database Editor: วาด Symbol คอยล์และวาง Node, Component Wizard จากตัวเดิม, Pin Assignment และ Save To Database — 9 ขั้น
04

สร้าง Model ของตู้

New Model, Model Properties, Mounting Description ให้ตรงกับราง, Insert Slot และปิด E³.dbe โดยไม่บันทึก — 6 ขั้น

Motor Control Lab

ฝึกวงจรควบคุมมอเตอร์ทีละด่าน: เล่นด่านในเกมให้ผ่านก่อน แล้วเขียนแบบวงจรเดียวกันใน E³.series 2027 — Lab 00 เตรียม Database ของตัวเอง แล้วต่อด้วย Lab 01–06

▶

เกม Motor Control Lab

ต่อวงจรควบคุมมอเตอร์ 10 ด่าน เล่นในเบราว์เซอร์ได้ทันที หรือดาวน์โหลดไปเล่นแบบออฟไลน์บน Windows
00

เตรียม Database

Copy Database ไปโฟลเดอร์ของตัวเอง, Configure Databases, เลือกใช้ แล้ว Backup / Compact and Repair — 6 ขั้น
01

First Light ไฟดวงแรก

ด่าน 1: สวิตช์กับหลอดไฟบน Sheet A4 — Component, Signal reference, Connection, สายและป้ายสาย — 13 ขั้น
02

First Motor มอเตอร์ตัวแรก

ด่าน 2: วงจรกำลัง 3 เฟส + วงจรควบคุมบน 2 Sheet, Autoconnect, Multi-Connection, View → Levels — 14 ขั้น
03

Self-holding กดครั้งเดียวค้าง

ด่าน 3: Terminal บนจุดต่อ bus, STOP + NO 13-14 จับค้าง, Angle connection, สาย BK / RD / BU — 14 ขั้น
04

Overload + ไฟสถานะ

ด่าน 4: Overload relay -F1, NC 95-96 / NO 97-98, ไฟ RUN / TRIP และเปลี่ยนเลขสาย — 11 ขั้น
05

JOG เดินทีละนิด

ด่าน 5: ปุ่ม JOG (Push Button NO NC) ต่อขนานกับวงจรจับค้าง, เลขสาย 2 หลัก — 11 ขั้น
06

เดินหน้า-ถอยหลัง (Interlock)

ด่าน 7: -K2 สลับเฟส, Interlock NC 21-22 ทั้งสองฝั่ง, Angle connection — 9 ขั้น
