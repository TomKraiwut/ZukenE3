Schematics

🔌

🗄️

⚙️

Database Editor

สร้าง Symbol, Component และ Model เองเมื่อของมาตรฐานไม่พอ พร้อมตรวจสอบฐานข้อมูลด้วย COM API

Zuken E3.series คืออะไร?

E3.series เป็นซอฟต์แวร์ของ Zuken สำหรับออกแบบระบบไฟฟ้า (E3.schematic), ระบบสายไฟ/สายเคเบิล (E3.cable — Wiring & Cable Harness), และแผงควบคุม (E3.panel — Panel Layout) ใช้กันแพร่หลายในอุตสาหกรรมยานยนต์ เครื่องจักรอุตสาหกรรม และระบบราง ทุกโมดูลอ้างอิงข้อมูลชุดเดียวกันแบบ Object-Oriented (Symbol/Component ในฐานข้อมูล กลายเป็น Device เมื่อวางในโปรเจกต์) ทำให้ BOM, Wire List และรายงานต่างๆ ตรงกับแบบจริงเสมอ โดยไม่ต้องส่งข้อมูลข้ามโมดูลเอง

อัพเดทที่น่าสนใจใน E3.series 2026: Search and Replace สำหรับ Texts/Attributes, คำสั่ง Update All Models in Project, ปรับปรุง Database Editor (ลบ Contour และบันทึกออบเจกต์ผ่าน Tree View ได้โดยตรง) และปรับปรุงการ Import STEP ไฟล์ในฝั่ง Panel Database — อ้างอิงจากคู่มือ E3.Update 2026

ใช้เว็บนี้ยังไง

  1. เริ่มที่เมนู Schematics ถ้ายังไม่เคยเปิดโปรแกรมมาก่อน — มีทั้งพื้นฐานและตัวอย่างฝึกทำในหน้าเดียว
  2. ไปที่ Cable เมื่อจะออกแบบ Wiring/Cable Harness ที่ต้องผลิตจริง
  3. ดู Panel เมื่อจะออกแบบเลย์เอาต์ตู้คอนโทรล (Mounting Rail/Cable Duct/Terminal)
  4. ดู Database Editor เมื่อของมาตรฐานในฐานข้อมูลไม่พอ ต้องสร้าง Symbol/Component/Model เอง

ไฟล์ตัวอย่างจริง: วางไฟล์โปรเจกต์ .e3s ของคุณไว้ในโฟลเดอร์ examples/ ของ repo นี้ได้ แล้วใส่ลิงก์ดาวน์โหลดในหน้าโมดูลที่เกี่ยวข้อง
