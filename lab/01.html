Zuken E3 Tutorial

01. First Light ไฟดวงแรก

วัตถุประสงค์การเรียนรู้

  1. สร้างโปรเจกต์ใหม่ ตั้ง Sheet A4 และ Title block
  2. วาง Component, Signal reference และต่อ Connection
  3. ตั้งชื่อ Signal (L1 / N) ใส่สาย H07V-K 1.5 mm² และให้ป้ายสายแสดงขนาดกับสี
  4. ใช้ Device window ดู Placement, Jump และ Highlight

Lab แรกบน E³.schematic: จากโปรเจกต์เปล่าไปถึงวงจรสวิตช์กับหลอดไฟหนึ่งดวง ได้ฝึกวาง Component, Signal reference, Connection, ใส่สายและป้ายสาย

ด่านในเกม: Lab นี้ตรงกับด่าน 1 ของเกม Motor Control Lab — ลองต่อวงจรในเกมก่อน แล้วค่อยเขียนแบบเดียวกันใน E³ ไปหน้าเกม →

ภาพรวม: 9 ขั้นตอน จากโปรเจกต์เปล่าถึงวงจรไฟดวงแรก

ลำดับหัวข้อทำอะไร

สิ่งที่ต้องมี: E3.series 2027 (E3.schematic) · Database: E3_DB_Symbol.mdb · Component: Switch NO, Lamp · Template: PROJECT_IEC

3 เส้น สาย H07V-K 1.5 mm² ในวงจรนี้

เป้าหมาย: เปิดสวิตช์แล้วหลอดไฟติด ปิดสวิตช์แล้วหลอดไฟดับ

  1. 1L1 ไฟเข้าจาก Signal reference ด้านบน
  2. 2-S1 Switch NO (สวิตช์แบบกดค้าง)
  3. 3-H1 Lamp หลอดไฟ
  4. 4N นิวทรัลกลับที่ Signal reference ด้านล่าง
  5. 5Title block A4 · Basic Circuit · Hitachi / 01
โจทย์จากเกม: ห้องเก็บอะไหล่ยังไม่มีไฟ ช่วยต่อสวิตช์กับหลอดไฟให้หน่อย เล่นด่านนี้ในเกม →

ขั้นที่ 1: สร้างโปรเจกต์ใหม่ (File → New)

  1. 1เมนู File → New (Ctrl+N)
  2. 2E3 สร้างโปรเจกต์ Untitled ให้ทันที ไม่มีหน้าต่างถาม
  3. 3ได้ Sheet 1 มาพร้อมกัน จาก Template PROJECT_IEC

ขั้นที่ 1 (ต่อ): บันทึกเป็น Lab01 (Save As)

  1. 1กด F12 (File → Save As) แล้วเลือกโฟลเดอร์ทำงาน
  2. 2File name พิมพ์ Lab01
  3. 3กด Save ไฟล์จะเป็น Lab01.e3s
ข้อควรจำ: บันทึกตั้งแต่ต้น แล้วกด Ctrl+S เป็นระยะ ชื่อบนหัวต่างจะเปลี่ยนจาก Untitled เป็น Lab01

ขั้นที่ 2: เปิด Sheet Properties แล้วเลือก Format A4

  1. 1แท็บ Sheet คลิกขวาที่ Sheet 1 → Sheet Properties...
  2. 2Format กดลูกศร dropdown
  3. 3เลือก A4

ขั้นที่ 2 (ต่อ): ใส่ชื่อ Sheet, Customer และ Order number

  1. 1Name (1) Basic Circuit
  2. 2Customer Hitachi
  3. 3Order number 01 (เลื่อนลงไปท้ายรายการ)
  4. 4กด OK
ระวัง: คลิกที่ช่อง Entry ให้ตรง อย่าคลิกโดน checkbox 'Prefer single pin placement'

ขั้นที่ 2 (ผลลัพธ์): Sheet A4 พร้อม Title block

  1. 1Hitachi / 01 มาจาก Customer และ Order number
  2. 2Basic Circuit มาจาก Name (1)
ตรวจ: Messages แจ้ง 'Sheet border of sheet 1 changed from DINA3 to A4'

ขั้นที่ 3: วาง Component -S1 Switch NO และ -H1 Lamp

  1. 1แท็บ Component ขยายโฟลเดอร์ General
  2. 2ลาก Switch NO มาวางที่ช่อง B4
  3. 3E3 ตั้งชื่อให้เป็น -S1 อัตโนมัติ
  4. 4ลาก Lamp มาวางใต้ -S1 (ช่อง C4)
  5. 5ได้ -H1 ขา X1 / X2
เทคนิค: กดค้างแล้วลากช้า ๆ จนเห็นสัญลักษณ์ติดเมาส์ แล้วค่อยปล่อย ดูตำแหน่งที่ status bar ด้านล่าง

ขั้นที่ 4: ซูมดูแบบ (Zoom / Fit To Window)

  1. 1Zoom (Z) ลากกรอบส่วนที่ต้องการขยาย
  2. 2Fit To Window (O) กลับมาเห็นทั้งแผ่น
  3. 3Ctrl + ล้อเมาส์ ซูมเข้า-ออกที่ตำแหน่งเมาส์
ข้อควรจำ: ปุ่ม O / Z ใช้ได้เมื่อคลิกบน Sheet ก่อน (focus อยู่ที่หน้าแบบ) ไม่ใช่ที่ Tree

ขั้นที่ 5: วาง Signal reference (DESTINATION_AUTO)

  1. 1แท็บ Misc ขยาย Misc_Signal cross references
  2. 2ลาก DESTINATION_AUTO (Incoming)
  3. 3วางตัวแรกที่ช่อง A3 (จะเป็น L1)
  4. 4วางตัวที่สองที่ช่อง C3 (จะเป็น N)

ขั้นที่ 6: ต่อ Connection (Insert → Connection)

  1. 1เมนู Insert → Connection (C)
  2. 2คลิกที่ปลาย Signal reference บน → คลิกมุม → คลิกที่ขา 1 ของ -S1
  3. 3เส้นจะจบเองเมื่อคลิกโดนขา
  4. 4สั่ง Connection ใหม่ ต่อ -S1:2 → -H1:X1
  5. 5ต่อ -H1:X2 → มุม → Signal reference ล่าง
ตรวจ: ปลายเส้นที่ต่อถูกจะแสดงชื่อ Signal (#1, #3) ที่ Signal reference

ขั้นที่ 7: เปลี่ยนชื่อ Signal เป็น L1

  1. 1คลิกขวาที่เส้นด้านบน → Connection Properties...
  2. 2Signal เปลี่ยน #1 เป็น L1 แล้วกด OK

ขั้นที่ 7 (ต่อ): เส้นล่างเป็น N แล้วตรวจใน Signal tree

  1. 1ทำซ้ำกับเส้นล่าง: Signal = N
  2. 2เมนู View → Signal Tree ต้องเห็น L1, N และ #2 (เส้นระหว่าง -S1 กับ -H1)

ขั้นที่ 8: เลือกชนิดสาย แล้วใส่สาย (Insert default wire)

  1. 1Wire group H07V-K
  2. 2Core 1.5-BN
  3. 3CoreName_hori / CoreName_vert ป้ายบนสายแนวนอน / แนวตั้ง
  4. 4กดปุ่ม Insert default wire แล้วคลิกบน Connection ทีละเส้น จาก L1 ลงไป N
ข้อควรจำ: เลขสายรันตามลำดับที่ใส่ ใส่จากบนลงล่างจะได้สาย 1-2-3 เรียงตามวงจร

ขั้นที่ 9: ให้ป้ายสายแสดงขนาดและสี (Symbol Properties)

  1. 1คลิกขวาที่ป้ายเลขสาย (CoreName) → Symbol Properties...
  2. 2ติ๊ก Cross-section
  3. 3ติ๊ก Colour
  4. 4ติ๊ก Wire group แล้วกด OK
ทำซ้ำ: ทำกับป้ายสายครบทั้ง 3 เส้น

ขั้นที่ 9 (ผลลัพธ์): ป้ายสายครบทั้ง 3 เส้น

  1. 1สาย 1 L1 → -S1:1
  2. 2สาย 2 -S1:2 → -H1:X1 (ป้ายแนวตั้ง)
  3. 3สาย 3 -H1:X2 → N
ตรวจ: ทุกป้ายต้องแสดง 1.50 mm², สี และ H07V-K

ขั้นที่ 10: เปลี่ยนสายเส้น N เป็นสีฟ้า (Wire Properties)

  1. 1แท็บ Devices ขยาย <Wires>
  2. 2คลิกขวาสาย 3 (H07V-K-1.5-BN)
  3. 3เลือก Wire Properties...

ขั้นที่ 10 (ต่อ): Wire type = 1.5-BU

  1. 1Wire type คลิกช่อง เลือก 1.5-BU (ลากขยายคอลัมน์ได้ถ้าอ่านไม่ออก)
  2. 2สายที่เลือกอยู่: 3 แล้วกด OK
มาตรฐานสี (IEC / มอก. 11): L1 และสายหลังสวิตช์ = BN สีน้ำตาล · N = BU สีฟ้า

ขั้นที่ 11: Device window ดูตำแหน่ง (Placement)

  1. 1Placement -H1 อยู่ที่ /1.C4 (Sheet 1 แถว C คอลัมน์ 4)
  2. 2-S1 อยู่ที่ /1.B4
  3. 3ลองลาก -H1 ไปคอลัมน์ 5 สายตามไปเอง Placement เปลี่ยนเป็น /1.C5 จากนั้นกด Undo (Ctrl+Z) กลับตำแหน่งเดิม

ขั้นที่ 12: Jump + Highlight แล้ว Reset highlight

  1. 1ดับเบิลคลิกที่ช่อง Placement ของ Lamp
  2. 2E3 กระโดดไปที่ -H1 ซูมเข้าและ Highlight สีชมพู
  3. 3Reset highlight (Shift+F3) ล้าง highlight แล้วกด Fit To Window (O)

ขั้นที่ 13: บันทึกและตรวจผล

  1. 1<Wires> สาย 1-2-3 = 1.5-BN / 1.5-BN / 1.5-BU
  2. 2วงจร L1 → -S1 → -H1 → N ครบ แล้วกด Ctrl+S (Messages แจ้ง Lab01.e3s saved)
ทดสอบตามโจทย์: เปิดสวิตช์ -S1 แล้วไฟจาก L1 ไหลผ่าน -H1 ไป N หลอดติด / ปิดสวิตช์ วงจรขาด หลอดดับ

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
ลาก Component มาแล้ววางไม่ลงกดค้างแล้วลากช้า ๆ จนสัญลักษณ์ติดเมาส์ จึงปล่อยบน Sheet
ไม่เจอ Switch NO / Lamp ในแท็บ Componentตรวจว่า E3 ใช้ Database E3_DB_Symbol.mdb ของคอร์ส
Connection ไม่ติดขา (ไม่มีชื่อ Signal ที่ปลาย)คลิกให้โดนปลายขาพอดี หรือซูมเข้าก่อนต่อเส้น
Insert → Default Wire แล้วไม่มีสายใช้ปุ่ม Insert default wire บน toolbar แล้วคลิกบนเส้น
ป้ายสายแสดงแค่เลขSymbol Properties ติ๊ก Cross-section, Colour, Wire group
ช่อง Customer / Order หายไปหลังเปลี่ยน A4เลื่อนลงในรายการ ช่องอยู่ท้ายสุด
กด O แล้วไม่ Fitคลิกบน Sheet ก่อนให้ focus อยู่ที่หน้าแบบ
