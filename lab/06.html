06. เดินหน้า-ถอยหลัง (Interlock)

วัตถุประสงค์การเรียนรู้

  1. วาง -K2 และต่อวงจรกำลังแบบสลับเฟส
  2. ใช้ NC 21-22 ของคอนแทคเตอร์อีกตัวเป็น Interlock ในวงจรควบคุม
  3. ต่อ Connection และ Angle connection ฝั่ง REV แล้วตรวจแบบ

ต่อจาก Lab 03: เพิ่ม -K2 กลับทางหมุนมอเตอร์ (สลับเฟส) และ Interlock กันคอนแทคเตอร์ทั้งสองตัวดึงพร้อมกัน

ด่านในเกม: Lab นี้ตรงกับด่าน 7 ของเกม Motor Control Lab — ลองต่อวงจรในเกมก่อน แล้วค่อยเขียนแบบเดียวกันใน E³ ไปหน้าเกม →

ไขว้ NC ของ K2 กั้น Coil K1 · NC ของ K1 กั้น Coil K2

เป้าหมาย: FWD เดินหน้า · REV ถอยหลัง · ห้ามดึงพร้อมกัน

  1. 1-K1 เดินหน้า L1-L2-L3 → U-V-W
  2. 2-K2 ถอยหลัง สลับ U กับ W
  3. 3-S1 FWD + K1 13-14 จับค้าง
  4. 4-S3 REV + K2 13-14 จับค้าง
  5. 5NC 21-22 ของ -K2 กั้น Coil K1
  6. 6NC 21-22 ของ -K1 กั้น Coil K2
โจทย์จากเกม: ประตูม้วนคลังสินค้า: กดขึ้นเดินหน้า กดลงถอยหลัง ถ้า K1 กับ K2 ดึงพร้อมกันจะลัดวงจรระหว่างเฟส เล่นด่านนี้ในเกม →

ขั้นที่ 1: Open Lab03 แล้ว Save As Lab06

  1. 1File → Open... โฟลเดอร์ Lab03 → work เลือก Lab03
  2. 2กด Open
  3. 3F12 Save As → โฟลเดอร์ Lab06 → work · File name: Lab06
  4. 4กด Save

ขั้นที่ 2: ลบสายทั้งหมด (Delete Forced)

  1. 1Devices → <Wires> คลิกสาย 1
  2. 2Shift+คลิก สาย 12 (เลือกทั้งหมด)
  3. 3คลิกขวา → Delete Forced
แลปนี้ไม่ใส่สาย: เน้นวาดวงจรเดินหน้า-ถอยหลังให้ถูก · เส้น Connection บนแบบยังอยู่ครบ ลบเฉพาะสาย

ขั้นที่ 3: Sheet 1 วาง -K2 Contactor ข้าง -K1

  1. 1Sheet 1 · แท็บ Component: General → Contactor
  2. 2ลากวางที่ 168 / 164 ได้ -K2 (หน้าสัมผัสหลัก 1-2 / 3-4 / 5-6)
ระยะห่าง: -K1 อยู่ x 132 · -K2 อยู่ x 168 แนวเดียวกัน y 164

ขั้นที่ 4: ต่อ -K2 เข้า L1/L2/L3 และออกแบบสลับเฟส

  1. 1Insert → Connection K2:1 → L1 ที่ y 180 · K2:3 → L2 y 176 · K2:5 → L3 y 172
  2. 2K2:2 → เส้น W (x 140) y 144 · K2:4 → V y 140 · K2:6 → U (x 132) y 136
สลับ U กับ W: ขาออก K2 ไขว้กลับด้าน: 2→W · 4→V · 6→U มอเตอร์จึงหมุนกลับทาง · เส้นตัดกันได้ไม่ต่อกัน (ไม่มีจุดต่อ)

ขั้นที่ 4 (ต่อ): Angle connection ทั้ง 6 จุดต่อ

  1. 1ขาเข้า 3 จุด: Angle counter clockwise คลิกเส้นแนวนอนใกล้จุดต่อ
  2. 2ขาออก 3 จุด: Angle clockwise
  3. 3ผล: -K2 ต่อขนาน -K1 ด้านเข้า และไขว้ด้านออก
ทิศมุมเอียง: ถ้ามุมเอียงผิดทาง คลิกเครื่องมือเดียวกันซ้ำที่จุดเดิมเพื่อยกเลิก (กลับเป็นตัว T) แล้วใช้อีกทิศ

ขั้นที่ 5: Sheet 2 ย้าย Coil -K1 ลง แล้ววาง NC 21-22 ของ -K2

  1. 1Coil -K1 เดิม 132 / 116
  2. 2ลากลงที่ 132 / 92
  3. 3Devices: -K → -K2 ลาก NC (21,22) วางบนเส้นที่ 132 / 124
วางบนเส้น: ขา 21 / 22 ตรงกับเส้น E3 ตัดเส้นและแทรกให้เอง · NC ของ -K2 กั้นทาง Coil -K1

ขั้นที่ 6: -S3 REV, NO 13-14 + Coil ของ -K2, NC 21-22 ของ -K1

  1. 1-K1 → NC (21,22)
  2. 2-K2 → NO (13,14)
  3. 3-K2 → Coil
  4. 4Component Push Button NO ที่ 228 / 184 = -S3
  5. 5NO 13-14 -K2 ที่ 268 / 184
  6. 6Coil -K2 ที่ 228 / 92
  7. 7NC -K1 ที่ 228 / 124
ไขว้กัน: ฝั่ง REV ใช้ NC ของ -K1 · ฝั่ง FWD ใช้ NC ของ -K2 · ถ้าใช้ NC ของตัวเอง คอยล์จะตัดตัวเองทันทีที่ดูด

ขั้นที่ 7: Connection 6 เส้นฝั่ง REV

  1. 1S3:1 → มุม 180 / 208
  2. 2K2:13 → เส้น 228 / 208
  3. 3S3:2 → NC -K1:21
  4. 4K2:14 → เส้น 228 / 140
  5. 5NC -K1:22 → Coil -K2:A1
  6. 6Coil -K2:A2 → บัส N
วาดใหม่ อย่า copy: เส้นที่วาดใหม่ฝั่ง REV ได้ signal ของตัวเอง ถ้า copy เส้นฝั่ง FWD มาวาง ชื่อ signal จะซ้ำ E3 ถือว่าต่อถึงกัน

ขั้นที่ 7 (ต่อ): Angle connection 3 จุด

  1. 1เส้น y 208 ใกล้ 180: Angle counter clockwise
  2. 2จุดต่อ 228 / 208 (เกิดจาก Angle clockwise ที่เส้นเดียวกัน)
  3. 3กิ่ง K2:14 ที่ 228 / 140: Angle clockwise
ทิศมุมเอียง: มุมเกิดฝั่งไหนขึ้นกับทิศของเครื่องมือ ลองแล้วดูผล ถ้าไม่ตรงคลิกซ้ำเพื่อยกเลิกแล้วใช้อีกทิศ

ขั้นที่ 8: Terminal -X4:2 บนจุดต่อ N

  1. 1Devices: -X → -X4 คลิกขวาขั้ว 1
  2. 2Insert Terminal ได้ขั้ว 2
  3. 3ลากขั้ว 2 วางบนจุดต่อ N ที่ 228 / 56
ทำหลังต่อเส้น: ต้องมีเส้น Coil -K2 → N ก่อนจึงเกิดจุดต่อให้วาง Terminal (วิธีเดียวกับ Lab 04)

ขั้นที่ 9: ตรวจแบบ แล้วทดสอบตามโจทย์

  1. 1กด FWD → K1 ดูด จับค้าง · NC 21-22 ของ K1 เปิด
  2. 2กด REV ขณะเดินหน้า → K2 ไม่ดูด (ถูก NC ของ K1 กั้น)
  3. 3กด STOP → หยุด · กด REV → K2 ดูด ถอยหลัง
  4. 4กด FWD ขณะถอยหลัง → K1 ไม่ดูด (ถูก NC ของ K2 กั้น)
ตรวจครบ: ตำแหน่งตรงไฟล์ตัวอย่าง · ไม่มีสาย · -X4:2 อยู่ใต้ Coil -K2 · File → Save

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
กด FWD แล้ว K2 ดูดด้วยเส้นฝั่ง REV ชื่อ signal ซ้ำกับฝั่ง FWD (copy มา) · ลบแล้ววาดใหม่ด้วย Insert → Connection
คอยล์ดูดแล้วตัดตัวเองNC 21-22 ต้องเป็นของอีกตัว (ไขว้) ไม่ใช่ของตัวเอง
ได้ -K3 แทน Coil ของ -K2Coil / NO / NC ต้องลากจาก Device tree ของ -K2 ไม่ใช่จากแท็บ Component
มุมเอียงไม่ตรงตัวอย่างคลิกเครื่องมือเดียวกันซ้ำที่จุดเดิมเพื่อยกเลิก แล้วลองอีกทิศ
วาง Terminal ไม่ได้ต่อเส้น Coil → N ให้เกิดจุดต่อก่อน
