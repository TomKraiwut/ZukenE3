05. JOG เดินทีละนิด

วัตถุประสงค์การเรียนรู้

  1. วาง Push Button NO NC เป็นอุปกรณ์ตัวเดียว (-S3 JOG) แล้ววาง NC 3-4 จาก Device tree
  2. ต่อ Connection และ Angle connection ของวงจร JOG
  3. เปลี่ยนเลขสายเป็น 2 หลัก และซ่อนป้ายสายที่ซ้อนกัน

ต่อจาก Lab 03: เพิ่มปุ่ม JOG ให้มอเตอร์เดินทีละนิดเฉพาะตอนกดค้าง ขณะที่ START ยังเดินค้างได้ตามเดิม

ด่านในเกม: Lab นี้ตรงกับด่าน 5 ของเกม Motor Control Lab — ลองต่อวงจรในเกมก่อน แล้วค่อยเขียนแบบเดียวกันใน E³ ไปหน้าเกม →

15 เส้น กำลัง BK 01–06 · ควบคุม RD 07–10, 12–15 · N BU 11

เป้าหมาย: START เดินค้าง · JOG เดินเฉพาะตอนกดค้าง

  1. 1-S2 STOP NC กดแล้วหยุด
  2. 2-S1 START NO กดแล้วเดิน
  3. 3-S3 JOG NO 1-2 ขนาน START สั่งเดิน
  4. 4-S3 JOG NC 3-4 ตัดทางจับค้างตอนกด JOG
  5. 5-K1 13-14 หน้าสัมผัสจับค้าง (อนุกรมกับ NC 3-4)
โจทย์จากเกม: เครื่องตัดแผ่นเหล็ก: ช่างต้องขยับใบมีดทีละนิด กด JOG เดิน ปล่อยแล้วหยุดทันที แต่ตอนผลิตกด START แล้วเดินค้าง เล่นด่านนี้ในเกม →

ขั้นที่ 1: Open Lab03 แล้ว Save As Lab05

  1. 1File → Open... โฟลเดอร์ Lab03 → work เลือก Lab03
  2. 2กด Open
  3. 3F12 Save As → โฟลเดอร์ Lab05 → work · File name: Lab05
  4. 4กด Save

ขั้นที่ 2: Sheet 2 ลบสาย 9 และกิ่ง K1:13 เดิม

  1. 1แท็บ Devices → <Wires> คลิกขวาสาย 9 (S2:2 → K1:13)
  2. 2Delete Forced
  3. 3คลิกเส้นกิ่ง K1:13 (แนวนอน y 208) → Delete
ทำไมลบ: K1:13 จะไม่ต่อกับ STOP ตรง ๆ แล้ว แต่ต่อผ่าน NC 3-4 ของ JOG

ขั้นที่ 3: ย้าย Coil, -S1 และ NO 13-14 ของ -K1

  1. 1Coil -K1 132 / 116
  2. 2-S1 132 / 184
  3. 3-K1 13-14 180 / 184
  4. 4ลาก Coil ลงที่ 132 / 100
  5. 5ลาก -S1 ลงที่ 132 / 180
  6. 6ลาก 13-14 ลงที่ 180 / 160
ดูตำแหน่ง: status bar มุมขวาล่างบอกพิกัด · ลากแนวตั้งอย่างเดียว ถ้าเลยให้ลากแก้อีกครั้ง

ขั้นที่ 4: วาง Push Button NO NC ได้ -S3 (NO 1-2)

  1. 1แท็บ Component: General → Push Button NO NC
  2. 2ลากวางที่ 228 / 184 ได้หน้าสัมผัส NO 1-2 ของ -S3
Component ใหม่: ปุ่มเดียวมี 2 หน้าสัมผัส: NO 1-2 และ NC 3-4 · ลากจาก Component ได้ชุดแรก (NO) ก่อน

ขั้นที่ 5: NC 3-4 จาก Device tree แล้วตั้งชื่อ -S3 JOG

  1. 1Devices: -S → -S3 ลาก NC (3,4)
  2. 2วางที่ 180 / 196 เหนือ 13-14 ของ -K1
  3. 3คลิก -S3 → F2 พิมพ์ -S3 JOG → Enter
Device เดียว: NO และ NC อยู่ใต้ -S3 ตัวเดียว เปลี่ยนชื่อครั้งเดียวได้ทั้ง 2 สัญลักษณ์ · ใต้ NC มี /2.C5 บอกว่า NO อยู่ไหน

ขั้นที่ 6: Connection 4 เส้น แล้ว Angle connection 3 จุด

  1. 1NC:4 → K1:13
  2. 2NO:1 → เส้น 132 / 216
  3. 3NC:3 → เส้น y 216
  4. 4NO:2 → มุมเส้น 180 / 140
  5. 5Angle connection clockwise ใกล้จุดต่อ 132 / 216
  6. 6จุดต่อ 180 / 216
  7. 7จุดต่อ 180 / 140
วิธีจาก Lab 03: Insert → Connection คลิกขาต้นทางแล้วปลายทาง · กิ่งที่เป็นตัว T ต้องทำมุมเอียงก่อนจึงใส่สายได้

ขั้นที่ 7: เปลี่ยนเลขสายเป็น 2 หลัก 01–11

  1. 1<Wires> คลิกสาย → F2 พิมพ์เลขใหม่ → Enter
  2. 21–8 → 01–08
  3. 310 → 09 · 11 → 10 · 12 → 11
ทำไม 2 หลัก: เรียงในตารางสายได้ถูก (01, 02 … 15) · สาย 9 เดิมลบไปแล้ว จึงเลื่อนเลขให้ต่อเนื่อง

ขั้นที่ 8: สาย 10 (K1:14 → S1:2) ลบแล้วใส่ใหม่บนแนว y 140

  1. 1<Wires> คลิกขวาสาย 10
  2. 2Delete Forced
  3. 3Wire type → 1.5-RD
  4. 4Insert default wire คลิกแนว y 140 ฝั่งซ้าย ได้สาย 12 → F2 เป็น 10
ทำไมใส่ใหม่: ป้ายสาย 10 เดิมอยู่ใต้ 13-14 ซึ่งตอนนี้มีสาย 13 วิ่งร่วม · ใส่ใหม่ให้ป้าย 10 อยู่บนแนว y 140 ตามตัวอย่าง

ขั้นที่ 9: สาย 12–15 ด้วย Insert default wire

  1. 112 K1:13 → NC:4 คลิกเส้นตั้ง x 180
  2. 213 K1:14 → NO:2 คลิกแนว y 140 ฝั่งขวา
  3. 314 S2:2 → NO:1 คลิกแนว y 216 ฝั่งซ้าย
  4. 415 NO:1 → NC:3 คลิกเส้นสั้นใต้จุดต่อ (เหนือ NC:3)
  5. 510 ที่ใส่ในขั้นที่ 8
ลำดับ = เลขสาย: กดปุ่ม Insert default wire ใหม่ทุกเส้น · ป้ายเกิดตรงจุดที่คลิก · คลิกแนว y 216 ฝั่งขวาแล้วไม่เกิดสาย ให้คลิกเส้นสั้นเหนือ NC:3

ขั้นที่ 10: ซ่อนป้าย '10,13' ใต้ 13-14

  1. 1ซูมเข้า ลากกรอบจากที่ว่างครอบป้ายใต้ K1:14 → คลิกขวา → Symbol Properties
  2. 2Cross-section ☐
  3. 3Colour ☐ แล้ว OK
ห้ามกด Delete ที่ป้าย: ลองลบป้ายแล้วเส้นแนว y 140 หายไปด้วย สาย 13 หลุด · ให้ซ่อนข้อความใน Symbol Properties แทน

ขั้นที่ 11: Save แล้วทดสอบตามโจทย์

  1. 1กด STOP → K1 ปล่อย มอเตอร์หยุด
  2. 2กด START → K1 ดูด → 13-14 ปิด ผ่าน NC 3-4 → เดินค้าง
  3. 3กด JOG ค้าง → NO 1-2 ปิด K1 ดูด → มอเตอร์เดิน
  4. 4ขณะกด JOG: NC 3-4 เปิด ตัดทางจับค้าง → ปล่อย JOG แล้วหยุดทันที
ตรวจครบ: สาย 15 เส้น 01–15 · -S3 JOG เป็น Device เดียว ไม่มีขาว่าง · File → Save

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
ได้ -S3 และ -S4 (2 ปุ่ม)หน้าสัมผัสที่ 2 ต้องลากจาก Device tree ของ -S3 ไม่ใช่จากแท็บ Component
Rename -S3 แล้วชื่อเปลี่ยนแค่ตัวเดียวแสดงว่าเป็นคนละ Device · ลบตัวที่เกินแล้วลาก NC จาก -S3
ใส่สายบนกิ่งไม่เกิดAngle connection ที่จุดต่อก่อน · หรือคลิกเส้นส่วนอื่นของกิ่ง
เลขสายไม่ตรงตัวอย่างเลขใหม่ = สูงสุด + 1 · ใช้ F2 Rename ใน <Wires>
กด Delete ที่ป้ายสายแล้วเส้นหายปิดไฟล์ไม่บันทึก เปิดไฟล์ที่ Save ล่าสุด · ซ่อนป้ายด้วย Symbol Properties
