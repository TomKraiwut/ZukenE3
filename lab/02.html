02. First Motor มอเตอร์ตัวแรก

วัตถุประสงค์การเรียนรู้

  1. แยกวงจรกำลังและวงจรควบคุมเป็น 2 Sheet ขนาด A3
  2. ใช้ Signal reference, Autoconnect และ Multi-Connection ต่อ L1 L2 L3 N
  3. วาง Contactor -K1, Motor -M1, Push Button -S1 และ Coil ของ -K1
  4. ซ่อน/แสดงเส้นนำสีเทาด้วย View → Levels และไฟล์ .vis

วงจรกำลัง 3 เฟส (Sheet 1) กับวงจรควบคุม (Sheet 2) ของมอเตอร์ตัวแรก: กด START ค้างมอเตอร์หมุน ปล่อยแล้วหยุด

ด่านในเกม: Lab นี้ตรงกับด่าน 2 ของเกม Motor Control Lab — ลองต่อวงจรในเกมก่อน แล้วค่อยเขียนแบบเดียวกันใน E³ ไปหน้าเกม →

ภาพรวม: วงจรกำลัง + วงจรควบคุม บน 2 Sheet

สิ่งที่ต้องมี: E3.series 2027 (E3.schematic) · Database: E3_DB_Symbol.mdb · Component: Contactor, Motor, Push Button NO · ผ่าน Lab 01 มาแล้ว

2 Sheet Power (กำลัง) + Control (ควบคุม)

เป้าหมาย: กด START ค้าง มอเตอร์หมุนเดินหน้า ปล่อยแล้วหยุด

  1. 1L1 L2 L3 N bus จาก Signal reference
  2. 2-K1 Contactor หน้าสัมผัสหลัก 1-2 / 3-4 / 5-6
  3. 3-M1 Motor 3 เฟส U V W
  4. 4-S1 Push Button NO (START กดค้าง)
  5. 5Coil -K1 A1 จาก -S1, A2 ไป N
โจทย์จากเกม: สายพานใช้มอเตอร์ 3 เฟส ปุ่มกดรับกระแสไม่ไหว จึงใช้ Contactor ตัดต่อไฟ ต้องหมุนเดินหน้าเท่านั้น เล่นด่านนี้ในเกม →

ขั้นที่ 1: New Project + Save As Lab02

  1. 1File → New ได้โปรเจกต์ Untitled + Sheet 1
  2. 2F12 Save As → File name: Lab02
  3. 3กด Save

ขั้นที่ 1 (ต่อ): Sheet Properties → A3, Motor Control / Power

  1. 1Format A3
  2. 2Name (1) Motor Control
  3. 3Name (2) Power แล้วกด OK
  4. 4Title block แสดง Motor Control / Power

ขั้นที่ 2: DESTINATION_AUTO ตัวแรก แล้ว Last Symbol (D)

  1. 1แท็บ Misc ลาก DESTINATION_AUTO มาวางมุมบนซ้าย
  2. 2Insert → Last Symbol (D) สัญลักษณ์ล่าสุดติดเมาส์ คลิกวางต่ำลง 1 ช่อง (4 mm)
ทำซ้ำ: Last Symbol อีก 2 ครั้ง ได้ DESTINATION 4 ตัว ห่างกัน 4 mm (L1 L2 L3 N) · ใช้เส้นนำสีเทาใน Sheet format เป็นจุดอ้างอิงให้ตรงกันทุก Sheet

ขั้นที่ 2–3: DESTINATION ×4 ซ้าย และ SOURCE ×4 ขวา

  1. 1DESTINATION_AUTO ×4 x เดียวกัน ห่างกัน 4 mm
  2. 2SOURCE_AUTO ×4 วางแบบเดียวกันทางขวา (ตัวแรกลากจาก Misc แล้ว Last Symbol)
ตรวจ: ทั้ง 8 ตัวต้องอยู่แถวเดียวกันคู่ซ้าย-ขวา Autoconnect จึงต่อได้

ขั้นที่ 4: Autoconnect → Inside Area Horizontal

  1. 1Insert → Autoconnect
  2. 2Inside Area Horizontal
  3. 3ลากกรอบจากมุมซ้ายบน
  4. 4ถึงมุมขวาล่าง ครอบ DESTINATION + SOURCE ทั้งหมด → ได้ bus 4 เส้น

ขั้นที่ 5: Signals tree → Rename (F2) เป็น L1 L2 L3 N

  1. 1View → Signal Tree เลือก #1 แล้วกด F2 พิมพ์ L1 Enter
  2. 2ทำต่อ #2 → L2, #3 → L3, #4 → N
ลำดับ: #1 คือเส้นบนสุด ดูได้จากข้อความที่ Signal reference (#1.1, #2.2 …)

ขั้นที่ 6: วาง -K1 Contactor และ -M1 Motor

  1. 1General → Contactor ลากมาวางใต้ bus
  2. 2General → Motor ลากมาวางใต้ -K1
  3. 3-K1 ขา 1 / 3 / 5 ด้านบน
  4. 4-M1 ขา U / V / W ตรงแนวขา 2 / 4 / 6
ระวัง: ขา U V W ต้องตรงแนวกับ 2 4 6 (x เดียวกัน) Autoconnect Vertical จึงต่อได้

ขั้นที่ 7: Autoconnect → Inside Area Vertical (K1 → M1)

  1. 1Insert → Autoconnect → Inside Area Vertical
  2. 2ลากกรอบครอบ -K1 และ -M1
  3. 3ได้ K1:2→U, K1:4→V, K1:6→W

ขั้นที่ 8: Multi-Connection ลากกรอบครอบขา K1:1/3/5

  1. 1Insert → Multi-Connection
  2. 2ลากกรอบครอบปลายขา 1 / 3 / 5 ของ -K1
  3. 3เลื่อนเมาส์ขึ้น จะเห็นเส้นยางยืด 3 เส้นพร้อมกัน

ขั้นที่ 8 (ต่อ): กด Shift ค้าง วางเมาส์ขวาของขากลางเล็กน้อย ที่ระดับ L3 แล้วคลิก

  1. 1K1:1 → L1 (เส้นซ้ายยาวที่สุด)
  2. 2K1:3 → L2
  3. 3K1:5 → L3 ตรงตำแหน่งเมาส์
  4. 4คลิกวาง → วงจรกำลังเสร็จ
ตำแหน่งเมาส์สำคัญ: Shift = ต่อหลายเส้นเป็นขั้นบันได ห่างกัน 1 grid. เมาส์ตรงหรือซ้ายของขากลางจะได้ลำดับกลับ (K1:1→L3) = มอเตอร์หมุนถอยหลัง · ดูภาพก่อนคลิก

ขั้นที่ 9: New Sheet A3 → Motor Control / Control

  1. 1Insert → Sheet... Format: A3
  2. 2กด OK ได้ Sheet 2
  3. 3Sheet Properties: Name (2) = Control (ค่าเดิม Power ติดมา ต้องลบก่อนพิมพ์)

ขั้นที่ 10: เลือกแถว L1 บน Sheet 1 แล้ว Copy

  1. 1คลิก DESTINATION L1
  2. 2Shift+คลิก เส้นท่อนซ้าย
  3. 3Shift+คลิก เส้นท่อนขวา (เส้นถูกแบ่งที่จุดต่อ K1)
  4. 4Shift+คลิก SOURCE L1 แล้ว Edit → Copy
ระวัง: คลิกช้า ๆ ทีละตัว Shift+คลิกเร็วเกินจะกลายเป็นดับเบิลคลิกและยกเลิกการเลือก. ที่เลือกแล้วเป็นเส้นประ

ขั้นที่ 10 (ต่อ): Paste บน Sheet 2 แล้วทำซ้ำกับ N

  1. 1Sheet 2: Edit → Paste เลื่อนเมาส์จน status bar แสดง 56 / 272 (ตำแหน่งเดิมบนเส้นนำ) แล้วคลิก → L1
  2. 2กลับ Sheet 1 เลือกแถว N, Copy แล้ว Paste ที่ 56 / 64 (ด้านล่าง) → N
ตรวจ: Signal reference แสดง cross-reference สีเขียว (/1.A…) ชื่อ Signal ยังเป็น L1 และ N

ขั้นที่ 11–12: วาง -S1 Push Button NO และ Coil ของ -K1

  1. 1แท็บ Component: ลาก Push Button NO → ได้ -S1
  2. 2แท็บ Devices: -K → -K1 ลาก Coil (ไอคอนสีส้ม = ยังไม่ได้วาง)
สำคัญ: Coil ต้องลากจาก Device tree ของ -K1 ตัวเดิม ถ้าลาก Contactor ใหม่จาก Component จะได้ -K2

ขั้นที่ 13: ต่อ Connection วงจรควบคุม แล้ว Save

  1. 1-S1 Push Button NO
  2. 2Coil -K1 A1 บน / A2 ล่าง
  3. 3Insert → Connection: S1:1 ขึ้นไป L1
  4. 4S1:2 → A1
  5. 5A2 → N แล้ว File → Save
ทดสอบตามโจทย์: กด -S1 ค้าง: L1 → S1 → Coil K1 → N K1 ดูด หน้าสัมผัส 1-2/3-4/5-6 ต่อ มอเตอร์หมุน ปล่อยปุ่ม K1 ปล่อย มอเตอร์หยุด

ขั้นที่ 14: ซ่อนเส้นนำสีเทาด้วย View → Levels

  1. 1View → Levels... (คีย์ L)
  2. 2แถว Level 3 = เส้นนำสีเทาใน Sheet format
  3. 3คลิกช่อง Symbol Graphic ให้เป็น ☐ (ไม่แสดง)
  4. 4กด OK
คอลัมน์: Symbol · Symbol Graphic · Symbol Text · Empty Text · Graphic · Text · Connections เส้นนำเป็นกราฟิกของ Sheet format จึงอยู่ใน Symbol Graphic

ขั้นที่ 14 (ต่อ): ก่อน / หลังซ่อนเส้นนำ

  1. 1ก่อน เห็นเส้นนำสีเทา ใช้วาง Signal reference ให้ตรงกันทุก Sheet
  2. 2หลัง เส้นนำหายไป แบบพร้อมพิมพ์ / ส่งออก PDF
เมื่อไหร่ใช้: เปิดเส้นนำตอนวางตำแหน่ง ปิดตอนตรวจแบบหรือพิมพ์ · บันทึกชุดการตั้งค่าเป็นไฟล์ .vis ได้ด้วย Write Configuration

ขั้นที่ 14 (ต่อ): บันทึกชุด Level เป็นไฟล์ .vis

  1. 1ตั้ง Level ให้เสร็จก่อน (แถว 3 Symbol Graphic ☐)
  2. 2กด Write Configuration
  3. 3File name: Guides_Off (นามสกุล .vis)
  4. 4กด Save
ใช้ทำอะไร: ไฟล์ .vis เก็บเฉพาะการแสดง / ซ่อนของทุก Level ใช้กับโปรเจกต์อื่นได้ ผู้สอนแจกไฟล์เดียวให้ทุกคนตั้งค่าเหมือนกัน

ขั้นที่ 14 (ต่อ): เปิดเส้นนำกลับ และเรียกไฟล์ .vis ด้วย Read Configuration

  1. 1เปิดกลับ: คลิกช่อง Symbol Graphic แถว 3 ให้เป็น ☑
  2. 2กด OK เส้นนำกลับมา
  3. 3Read Configuration เลือก Guides_Off.vis
  4. 4Reload level visibility ต้องเป็น ☑
  5. 5Open แล้ว OK เส้นนำหายอีกครั้งในคลิกเดียว
สลับเร็ว: ระหว่างวางตำแหน่งเปิดเส้นนำ (☑) · ก่อนพิมพ์ / ส่งออก PDF เรียก Guides_Off.vis

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
Multi-Connection ต่อผิดลำดับเฟส (K1:1→L3)วางเมาส์ตรงขากลางที่ระดับ L3 ไม่ใช่ขาซ้าย / Undo แล้วทำใหม่
Multi-Connection ไปจบที่ bus เดียวกันต้องกด Shift ค้างตอนคลิกวาง
เส้นขั้นบันไดไม่ลงบน busbus ต้องห่างกัน 1 grid (4 mm) ตอนวาง Signal reference
Insert → Last Symbol ขึ้น 'No symbol type selected'ต้องวางสัญลักษณ์อย่างน้อย 1 ครั้งก่อน
Paste แล้วเส้นขาดเป็นช่วงเลือกเส้นทุกท่อน (เส้นถูกแบ่งที่จุดต่อ) ก่อน Copy
ได้ -K2 แทน Coil ของ -K1ลบ -K2 แล้วลาก Coil จาก Device tree ของ -K1
Name (2) ได้ PowerControlลบข้อความเดิมก่อนพิมพ์ (End + Backspace)
ปิด Level 3 แล้วเส้นนำไม่หายต้องปิดคอลัมน์ Symbol Graphic ไม่ใช่ Symbol หรือ Text
