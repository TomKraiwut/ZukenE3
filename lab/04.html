04. Overload + ไฟสถานะ

วัตถุประสงค์การเรียนรู้

  1. แทรก Overload relay บนสายกำลัง 3 เส้นแล้วใส่สายใหม่
  2. แทรกหน้าสัมผัส NC 95-96 ก่อน STOP และใช้ NO 97-98 สั่งไฟ TRIP
  3. เปลี่ยนเลขสาย (F2 / Wire Properties) ให้เรียงตามแบบ
  4. ตรวจแบบแล้วทดสอบตามโจทย์

ต่อจาก Lab 03: เพิ่ม Overload relay -F1 กันมอเตอร์ไหม้ พร้อมไฟเขียว RUN และไฟแดง TRIP

21 เส้น กำลัง BK 1–6, 13–15 · ควบคุม RD / N BU 7–22

เป้าหมาย: OL ทริปแล้วมอเตอร์หยุด ไฟเขียว RUN ไฟแดง TRIP

  1. 1-F1 Overload relay 1-2 / 3-4 / 5-6
  2. 2NC 95-96 ทริปแล้วตัดวงจรควบคุมทั้งหมด
  3. 3NO 97-98 ทริปแล้วปิด จ่ายไฟให้ -H2
  4. 4-H1 RUN ติดตอน K1 ทำงาน
  5. 5-H2 TRIP ติดตอน OL ทริป
โจทย์จากเกม: มอเตอร์ทำงานเกินกำลังแล้วไหม้ ต้องมี Overload ตัดวงจร และมีไฟบอกสถานะให้ช่างเห็นจากหน้าตู้ เล่นด่านนี้ในเกม →

ขั้นที่ 1: Open Lab03 แล้ว Save As Lab04

  1. 1File → Open... โฟลเดอร์ Lab03 → work เลือก Lab03
  2. 2กด Open
  3. 3F12 Save As → โฟลเดอร์ Lab04 → work · File name: Lab04
  4. 4กด Save

ขั้นที่ 2: ย้าย -K1 ขึ้น เว้นที่ให้ Overload relay

  1. 1-K1 เดิม 132 / 164
  2. 2ลาก -K1 ขึ้นไปที่ 132 / 188 (/1.C3)
ดูตำแหน่ง: status bar มุมขวาล่างบอกพิกัด · 1 grid = 4 mm · ลากแนวตั้งอย่างเดียว เส้นยืดตามเอง

ขั้นที่ 3: Overload relay ลากวางบน 3 เส้นทีเดียว

  1. 1แท็บ Component: General → Overload relay
  2. 2ลากวางบนเส้น K1 → X2 ที่ 132 / 132 (/1.D3) ได้ -F1 ขา 1-2 / 3-4 / 5-6
E3 แทรกให้เอง: ขา 1 / 3 / 5 ตรงกับเส้น L1 L2 L3 → E3 ตัดเส้นและแบ่งสายให้ แต่ป้ายสายของสายที่ถูกแบ่งหายไป

ขั้นที่ 3 (ต่อ): ลบสายที่ถูกแบ่ง 4–6 และ 13–15 (Delete Forced)

  1. 1แท็บ Devices → <Wires> คลิกสาย 4 แล้ว Shift+คลิก สาย 6
  2. 2คลิกขวา → Delete Forced · ทำซ้ำกับ 13–15
  3. 3เหลือ 1–3 และ 7–12
ลบเฉพาะสาย: Delete Forced ใน <Wires> ลบสาย (core) เส้น Connection บนแบบยังอยู่ครบ

ขั้นที่ 3 (ต่อ): ใส่สายใหม่ 1.5-BK K1 → F1 ก่อน แล้ว F1 → X2

  1. 1Wire type → 1.5-BK
  2. 2ปุ่ม Insert default wire แล้วคลิกเส้น (กดปุ่มใหม่ทุกเส้น)
  3. 3K1 → F1 ที่ y 152 : ได้เลข 13–15
  4. 4F1 → X2 ที่ y 104 : ได้เลข 16–18
ตำแหน่งป้ายสาย: ป้ายเกิดตรงจุดที่คลิก · เลขใหม่ = เลขสูงสุด + 1 จึงใส่ K1 → F1 ก่อนให้ได้ 13–15 ตามตัวอย่าง

ขั้นที่ 3 (ต่อ): เปลี่ยนเลข 16–18 เป็น 4–6 และตั้งป้ายสาย

  1. 1<Wires> คลิกสาย 16 → F2 พิมพ์ 4 → Enter · 17 → 5 · 18 → 6
  2. 2ลากกรอบครอบป้าย 13–15 → คลิกขวา → Symbol Properties แบบ Lab 03
  3. 3Core in connection ☐ · Cross-section ☑ · Colour ☑ · ทำซ้ำกับ 4–6
ผลลัพธ์: 4–6 = F1 → X2 · 13–15 = K1 → F1 · ป้ายแสดง 1.50 mm² Black เหมือนสาย 1–3

ขั้นที่ 4: Sheet 2 ย้าย Coil, -S1 + 13-14, -S2 ลง

  1. 1ลาก Coil -K1 132 / 116 → 96
  2. 2คลิก -S1 + Shift+คลิก NO 13-14 ลาก 184 → 172
  3. 3คลิกเส้นกิ่ง K1:13 และ K1:14 (แนวนอน) → Delete
  4. 4ลาก -S2 236 → 208
  5. 5เส้นประ = สาย 9 / 11 ที่ไม่มีเส้นแล้ว
ทำไมลบกิ่ง: กิ่งเดิมต่ออยู่ที่ y 210 ถ้าย้าย -S2 ลงทั้งที่มีกิ่ง จุดต่อจะไปอยู่ผิดฝั่งของ -S2

ขั้นที่ 4 (ต่อ): ลบสาย 11 แล้วต่อกิ่ง K1:13 ใหม่ที่ y 192

  1. 1<Wires> คลิกขวาสาย 11 (K1:14 → S1:2)
  2. 2Delete Forced · สาย 9 เก็บไว้
  3. 3Insert → Connection คลิกขา K1:13
  4. 4คลิกเส้นตั้งที่ 132 / 192 แล้ว Angle connection clockwise ใกล้จุดต่อ
สาย 9 ต่อเอง: เมื่อมีเส้นกิ่งใหม่ สาย 9 (S2:2 → K1:13) กลับมาต่อบนเส้นเอง · สาย 11 ถูกแทนด้วยกิ่งของไฟ RUN

ขั้นที่ 5: NC 95-96 ของ -F1 แทรกก่อน STOP

  1. 1แท็บ Devices: -F → -F1 ลาก NC (95,96)
  2. 2E3 แบ่งสายให้: 7 = F1:95 → X3:1
  3. 316 = S2:1 → F1:96 (ไม่มีป้าย)
  4. 4วางบนเส้น X3 → S2 ที่ 132 / 236 (/2.B3)
Device เดียวกัน: NC ต้องลากจาก -F1 ตัวเดิม · OL ทริป → 95-96 เปิด → ตัดทั้งคอยล์ K1 และไฟ RUN

ขั้นที่ 5 (ต่อ): สาย 7, 8, 9 ใส่ใหม่ 1.5-RD ให้มีป้ายสาย

  1. 1Delete Forced สาย 8, 9, 16 · Rename 7 → 16
  2. 21.5-RD + Insert default wire: S2:1–F1:96, S1:1–S2:2, กิ่ง K1:13 ได้ 17–19
  3. 3Rename 17 → 7 · 18 → 8 · 19 → 9
  4. 4ลากกรอบป้าย → Symbol Properties: Core in connection ☐
  5. 5Cross-section ☑
  6. 6Colour ☑ แล้ว OK
ระวังตอนลากกรอบ: เริ่มลากจากที่ว่าง ถ้าเริ่มบนเส้น เส้นจะถูกลากย้ายไปแทน (แก้ด้วยการลากกลับ)

ขั้นที่ 6: NO 97-98 ของ -F1 และไฟ -H1 / -H2

  1. 1Devices: -F1 ลาก NO (97,98)
  2. 2วางที่ 220 / 172 (/2.C5)
  3. 3Component: General → Lamp วางที่ 180 / 80 ได้ -H1
  4. 4Lamp อีกตัววางที่ 220 / 80 ได้ -H2
ตำแหน่ง: -H1 อยู่ใต้ 13-14 ของ -K1 (x 180) · -H2 อยู่ใต้ 97-98 ของ -F1 (x 220) · ขา X2 อยู่ล่าง

ขั้นที่ 7: Connection ไฟ RUN / TRIP และกิ่ง H1 → S1–A1

  1. 1F1:97 → bus L1
  2. 2F1:98 → H2:X1
  3. 3K1:14 → H1:X1
  4. 4H1:X2 → bus N
  5. 5H2:X2 → bus N
  6. 6กิ่ง y 128 (x 180 → 132) + Angle clockwise 2 ปลาย
ทำไมต้องเอียง 2 ปลาย: กิ่งนี้มีจุดต่อแบบตัว T ทั้งซ้ายและขวา มุมเอียงบอก E3 ว่าสายไป S1:2 กับ H1:X1

ขั้นที่ 8: Terminal -X3:2, -X4:2, -X4:3 บนจุดต่อ

  1. 1Devices: -X → -X3 คลิกขวาขั้ว 1
  2. 2Insert Terminal ได้ขั้ว 2
  3. 3ลากขั้ว 2 วางบนจุดต่อ L1 ที่ 220 / 272
  4. 4-X4: Insert Terminal 2 ครั้ง ลากขั้ว 2 ไป 180 / 56
  5. 5ลากขั้ว 3 ไป 220 / 56
ทำหลังต่อเส้น: ต้องมีเส้นลงก่อนจึงเกิดจุดต่อให้วาง Terminal · E3 เตือน pins aren't linked ได้ ไม่กระทบ

ขั้นที่ 9: สาย 17–22 (RD / BU) ตามลำดับ

  1. 117 H1:X2 → X4:2 BU
  2. 218 กิ่ง H1:X1 → S1:2 RD
  3. 319 H1:X1 → K1:14 RD
  4. 420 F1:97 → X3:2 RD
  5. 521 F1:98 → H2:X1 RD
  6. 622 H2:X2 → X4:3 BU
  7. 71.5-BU สำหรับ N
  8. 81.5-RD สำหรับวงจรควบคุม
ลำดับ = เลขสาย: ใส่ตามลำดับ 17 → 22 · เปลี่ยน Wire type ก่อนเส้นที่สีต่าง · กดปุ่ม Insert default wire ทุกเส้น

ขั้นที่ 9 (ต่อ): ป้ายสายใหม่แสดงเลข ขนาด สี

  1. 1ป้าย 10,18 เลือกแล้วลากลงไปใต้จุดต่อ (132 / 116) เหลือ 10
  2. 2Symbol Properties: Cross-section ☑ Colour ☑ (เลขสายคงไว้)
  3. 3ทำแบบเดียวกันกับ 17, 19, 21, 22
  4. 4ผล: เลข + 1.50 mm² + สี
  5. 5ป้าย 20: Core in connection ☐ (ตามตัวอย่าง)
ตั้งใจแสดงเลข: ป้ายสายใหม่แสดงเลขสายด้วย เพื่อให้ตรวจกับตารางสายได้ง่าย (ตามไฟล์ตัวอย่างของผู้สอน)

ขั้นที่ 10: ตั้งชื่อไฟ -H1 RUN / -H2 TRIP แล้ว Save

  1. 1Devices: -H → คลิก -H1 → F2
  2. 2พิมพ์ -H1 RUN → Enter
  3. 3-H2 → F2 → -H2 TRIP → Enter
  4. 4File → Save
ชื่อบนแบบ: ชื่อ Device แสดงข้างหลอดทันที ช่างรู้ว่าดวงไหนคือ RUN ดวงไหนคือ TRIP

ขั้นที่ 11: ตรวจแบบ แล้วทดสอบตามโจทย์

  1. 1/2.C5 /2.B3 cross reference บอกว่า NO / NC อยู่ที่ไหน
  2. 2OL ทริป → 95-96 เปิด → K1 ปล่อย มอเตอร์หยุด
  3. 397-98 ปิด → -H2 TRIP ติด
  4. 4START → K1 ดูด จับค้าง → -H1 RUN ติด
  5. 5STOP → หยุด · -H1 ดับ
ตรวจครบ: สาย 21 เส้น: 1–10, 12–22 · ไม่มีสาย 11 · ระหว่างขั้ว X3:1–X3:2 และ X4:1–X4:3 ยังไม่ใส่สาย (ข้ามไปก่อน)

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
วาง Overload relay แล้วป้ายสายหายDelete Forced สายที่ถูกแบ่ง แล้ว Insert default wire ใหม่
เลขสายใหม่ไม่ตรงตัวอย่างเลขใหม่ = สูงสุด + 1 · ใช้ F2 Rename ใน <Wires> (ชื่อชนกันให้ใช้ชื่อชั่วคราว)
ลากกรอบแล้วเส้นถูกย้ายเริ่มลากกรอบจากที่ว่าง · ลากเส้นกลับที่เดิม
Undo แล้วไม่กลับแก้ด้วยมือ (ลากกลับ) แล้วตรวจตำแหน่งที่ status bar
คลิกขวาป้ายแล้วไม่มี Symbol Propertiesคลิกโดนข้อความ ให้ลากกรอบครอบป้ายแทน
ใส่สายบนกิ่งได้ขาเดียวAngle connection ที่จุดต่อก่อน (กิ่ง H1 ทำทั้ง 2 ปลาย)
Ctrl+S ไม่บันทึกใช้ปุ่ม Save บน toolbar หรือ File → Save
