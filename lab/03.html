03. Self-holding กดครั้งเดียวค้าง

วัตถุประสงค์การเรียนรู้

  1. วาง Terminal บนจุดต่อ bus และซ่อนข้อความ Terminal ด้วย Symbol Properties
  2. ใส่สายวงจรกำลัง 1.5-BK และสายวงจรควบคุม 1.5-RD / N 1.5-BU ตาม IEC 60204-1
  3. วาง Push Button NC และหน้าสัมผัส NO 13-14 ของ -K1 เป็นวงจรจับค้าง
  4. ใช้ Angle connection ที่จุดต่อเส้นกิ่ง

ต่อจาก Lab 02: เพิ่ม Terminal, ปุ่ม STOP และหน้าสัมผัสจับค้าง (Self-holding) ให้กด START ครั้งเดียวแล้วมอเตอร์หมุนค้างจนกด STOP

ด่านในเกม: Lab นี้ตรงกับด่าน 3 ของเกม Motor Control Lab — ลองต่อวงจรในเกมก่อน แล้วค่อยเขียนแบบเดียวกันใน E³ ไปหน้าเกม →

เป้าหมาย: กด START ครั้งเดียว มอเตอร์หมุนค้าง กด STOP แล้วหยุด

  1. 1-X1 Terminal บนจุดต่อ bus L1 L2 L3
  2. 2-K1 ย้ายลงมา /1.C3
  3. 3-X2 Terminal เหนือมอเตอร์
  4. 4-S2 STOP (Push Button NC)
  5. 5NO 13-14 ของ -K1 จับค้างขนาน -S1
  6. 6-X3 / -X4 Terminal บนจุดต่อ L1 และ N
โจทย์จากเกม: พนักงานต้องยืนกดปุ่มตลอดกะ ต้องการกด START ครั้งเดียวแล้วปั๊มทำงานค้าง จนกว่าจะกด STOP เล่นด่านนี้ในเกม →

ขั้นที่ 1: Open Lab02 แล้ว Save As Lab03

  1. 1File → Open... โฟลเดอร์ Lab02 → work เลือก Lab02
  2. 2กด Open
  3. 3F12 Save As → File name: Lab03
  4. 4กด Save

ขั้นที่ 1 (ต่อ): เปิดเส้นนำสีเทา (View → Levels)

  1. 1แถว 3 Symbol Graphic ให้เป็น ☑
  2. 2กด OK
  3. 3เส้นนำซ้าย: แถว bus
  4. 4เส้นนำบน: แนวคอลัมน์ (x 132 …)
ทำไม: Lab 02 ปิดเส้นนำไว้ตอนจบ · Lab นี้วาง Terminal และอุปกรณ์ตามเส้นนำ จึงเปิดกลับก่อน

ขั้นที่ 2: ย้าย -K1 และ -M1 ลง เว้นที่ให้ Terminal

  1. 1-K1 เดิม 132 / 200
  2. 2-M1 เดิม 132 / 152
  3. 3ลาก -M1 ลงก่อนไปที่ 132 / 68 (/1.E3)
  4. 4แล้วลาก -K1 ลงไปที่ 132 / 164 (/1.C3)
ลำดับ: ย้าย -M1 ก่อน ไม่งั้น -K1 จะลงไปทับ -M1 · Connection ยืดตามสัญลักษณ์เอง · ดูตำแหน่งที่ status bar

ขั้นที่ 3: Terminal -X1 บนจุดต่อ bus L1

  1. 1แท็บ Component: General → Terminal
  2. 2ลากวางบนจุดต่อ bus L1 กับเส้นลง K1:1 (132 / 272) ได้ -X1:1
ระวัง: วางบนจุดต่อ bus ไม่วางกลางเส้น (สายข้ามแผ่นจะหาปลายไม่เจอ)

ขั้นที่ 3 (ต่อ): Insert Terminal เพิ่มขั้ว 2, 3 แล้ววางบน L2 / L3

  1. 1แท็บ Devices: -X → -X1 คลิกขวาขั้ว 1
  2. 2Insert Terminal ได้ขั้ว 2 และทำซ้ำได้ 3
  3. 3ลากขั้ว 2 จาก tree วางบนจุดต่อ L2 (136 / 268)
  4. 4ลากขั้ว 3 วางบนจุดต่อ L3 (140 / 264)
ระวัง: ขั้วที่ยังไม่วาง เมนูคลิกขวามีรายการเพิ่ม (Place One-by-One) ตำแหน่ง Insert Terminal เลื่อนลง อ่านชื่อก่อนคลิก

ขั้นที่ 4: Terminal -X2 เหนือ -M1

  1. 1ลาก Terminal วางบนเส้น K1:2 → U ที่ 132 / 80 ได้ -X2
  2. 2Insert Terminal 2 ครั้ง ได้ขั้ว 2, 3
  3. 3ลากขั้ว 2, 3 วางที่ 136 / 80 และ 140 / 80

ขั้นที่ 4 (ต่อ): ซ่อนข้อความ Terminal ด้วย Symbol Properties

  1. 1ลากกรอบครอบ Terminal -X1 ทั้ง 3 ขั้ว → คลิกขวา → Symbol Properties...
  2. 2Device designation ☐ (ซ่อน -X1)
  3. 3Component code ☐ (ซ่อนคำว่า Terminal) แล้ว OK
ทำไม: Terminal 3 ขั้วอยู่ชิดกัน ข้อความ -X1 / Terminal ซ้อนทับกันจนอ่านไม่ออก

ขั้นที่ 4 (ต่อ): ให้ -X1 แสดงที่ขั้ว 1 ตัวเดียว แล้วทำซ้ำกับ -X2

  1. 1-X1 แสดงครั้งเดียวที่ขั้ว 1
  2. 2คลิกเลือกขั้ว 1 ตัวเดียว → คลิกขวา → Symbol Properties
  3. 3Device designation ☑ แล้ว OK · ทำซ้ำทั้งหมดกับ -X2
ผลลัพธ์: -X1 1 2 3 และ -X2 1 2 3 อ่านง่าย ไม่มีข้อความซ้อน · Sheet 2 (-X3, -X4) ไม่ต้องทำ

ขั้นที่ 5: สายวงจรกำลัง 1.5-BK (เลขสาย 1–6)

  1. 1Wire group H07V-K
  2. 2Wire type 1.5-BK
  3. 3ปุ่ม Insert default wire แล้วคลิกเส้น 1 ครั้ง (กดปุ่มใหม่ทุกเส้น)
  4. 4X1 → K1 : เลข 1–3
  5. 5K1 → X2 : เลข 4–6
X2 → M1 ไม่ใส่สาย: Terminal -X2 คือขอบตู้ สายมอเตอร์เดินนอกตู้ · เลขสายเรียงตามลำดับที่ใส่ ใส่วงจรกำลังก่อน

ขั้นที่ 5 (ต่อ): ป้ายสายแสดงขนาดและสี (Symbol Properties)

  1. 1ลากกรอบครอบป้ายสาย 1–3 → คลิกขวา → Symbol Properties...
  2. 2Core in connection ☐ (เลขสาย)
  3. 3Cross-section ☑
  4. 4Colour ☑ แล้ว OK
  5. 5ป้ายสายแสดง 1.50 mm² Black · ทำซ้ำกับสาย 4–6
อ่านแบบ: ช่างประกอบตู้เห็นขนาดและสีสายจากแบบได้เลย · ทำเฉพาะ Sheet 1

ขั้นที่ 6–7: Sheet 2 ลบ Connection เดิม แล้วย้าย N, -S1, Coil

  1. 1คลิกเส้น L1 → S1
  2. 2Shift+คลิก เส้น S1 → A1
  3. 3Shift+คลิก เส้น A2 → N แล้วกด Delete
  4. 4เลือกแถว N (DESTINATION + เส้น + SOURCE) ลากลงไป y 56
  5. 5ลาก -S1 ไป 132 / 184 (/2.C3)
  6. 6ลาก Coil -K1 ไป 132 / 116 (/2.D3)
ทำไมลบก่อน: อุปกรณ์ย้ายทั้งแนวนอนและแนวตั้ง ถ้าย้ายทั้งที่มีเส้นต่ออยู่ เส้นจะหักเป็นขั้น · ลากทีละแกน ดู status bar

ขั้นที่ 8–9: วาง -S2 Push Button NC และ NO 13-14 ของ -K1

  1. 1General → Push Button NC ลากวางที่ 132 / 236 ได้ -S2 (STOP)
  2. 2แท็บ Devices: -K → -K1 ลาก NO (13,14) วางที่ 180 / 184 (/2.C4)
Device เดียวกัน: NO ต้องลากจาก -K1 ตัวเดิม ถ้าลาก Contactor ใหม่จาก Component จะได้ -K2

ขั้นที่ 10: Insert → Connection ต่อวงจรควบคุมใหม่

  1. 1Insert → Connection คลิกขาต้นทาง แล้วคลิกปลายทาง
  2. 2S2:1 → bus L1
  3. 3S2:2 → S1:1
  4. 4S1:2 → A1
  5. 5A2 → bus N
  6. 6K1:13 → กลางเส้น S2 – S1
  7. 7K1:14 → กลางเส้น S1 – A1
ปลายเส้นกลางเส้น: คลิกปลายบนเส้นที่มีอยู่ จะเกิดจุดต่อ (junction) · ขาที่มีเส้นแล้วต่อซ้ำไม่ได้

ขั้นที่ 10 (ต่อ): Angle connection ที่จุดต่อเส้นกิ่ง

  1. 1ปุ่ม Angle connection clockwise
  2. 2คลิกเส้นกิ่ง K1:13 ใกล้จุดต่อ
  3. 3กดปุ่มอีกครั้ง คลิกเส้นกิ่ง K1:14 ใกล้จุดต่อ (ได้มุมเอียงแบบเดียวกัน)
ทำไมต้องเอียง: จุดต่อแบบตัว T ทำให้ E3 ไม่รู้ว่าสายจากกิ่งจะไปขาไหน มุมเอียงบอกทิศ Insert default wire จึงใส่สายได้ครบ 2 ปลาย

ขั้นที่ 11: Terminal -X3 บนจุดต่อ L1 และ -X4 บนจุดต่อ N

  1. 1ลาก Terminal วางบนจุดต่อ bus L1 (132 / 272) ได้ -X3
  2. 2ลาก Terminal อีกตัววางบนจุดต่อ bus N (132 / 56) ได้ -X4
ทำหลังต่อเส้น: ต้องมีเส้นลงก่อน จึงเกิดจุดต่อให้วาง Terminal · -X3 กับ -X4 เป็นคนละแผง

ขั้นที่ 12: สายวงจรควบคุม 1.5-RD (เลข 7–11)

  1. 1Wire type → 1.5-RD
  2. 27: X3 → S2
  3. 38: S2 → S1
  4. 49: กิ่ง K1:13
  5. 510: S1 → A1
  6. 611: กิ่ง K1:14
วิธีเดิม: กดปุ่ม Insert default wire ก่อนคลิกทุกเส้น · กิ่งให้คลิกส่วนแนวตั้งของเส้นกิ่ง

ขั้นที่ 12 (ต่อ): N ใช้ 1.5-BU (เลข 12) แล้ว Save

  1. 1Wire type → 1.5-BU
  2. 212: A2 → X4 แล้ว File → Save
ระวัง: รายการ Wire type เลื่อนตามค่าที่เลือกอยู่ อ่านชื่อก่อนคลิก

ขั้นที่ 13–14: ตรวจ Device tree แล้วทดสอบตามโจทย์

  1. 1Contactor /1.C3 หน้าสัมผัสหลัก
  2. 2Coil /2.D3
  3. 3NO (13,14) /2.C4 จับค้าง
ทดสอบตามโจทย์: กด S1 → K1 ดูด → 13-14 ปิด จับค้าง → ปล่อย S1 มอเตอร์ยังหมุน · กด S2 → K1 ปล่อย → หยุด

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
ลาก Terminal ครั้งที่ 2 ได้ -X2 แทน -X1:2ลบออก แล้วใช้ Insert Terminal ที่ -X1 ใน Device tree
คลิกขวาขั้วแล้วเปิดหน้าต่าง New ViewCancel · ขั้วที่ยังไม่วาง Insert Terminal อยู่ต่ำลง อ่านชื่อเมนูก่อน
วาง Terminal กลาง bus แล้วสายข้ามแผ่นปลายลอยต่อเส้นลงก่อน แล้ววาง Terminal บนจุดต่อ
ใส่สายบนเส้นกิ่งได้ขาเดียว ปลายลอยทำ Angle connection ที่จุดต่อก่อน แล้วใส่สายใหม่
Angle connection คลิกแล้วไม่เปลี่ยนคลิกเส้นกิ่งให้ใกล้จุดต่อมากขึ้น
ย้ายอุปกรณ์แล้วไปไม่ตรงจุดลากทีละแกน ดู status bar ระยะ 1 grid = 4 mm
Insert default wire คลิกแล้วไม่เกิดสายกดปุ่มใหม่ทุกครั้งก่อนคลิกเส้น
ได้สีสายผิดDelete Forced สาย แล้วเลือก Wire type ใหม่
