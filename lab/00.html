00. เตรียม Database

วัตถุประสงค์การเรียนรู้

  1. Copy Database ของคอร์สไปไว้ในโฟลเดอร์งานของตัวเอง
  2. เพิ่ม Database ด้วย Configure Databases (Data Link → Access Database Engine 16.0) แล้วเลือกใช้
  3. Backup Database และใช้ Compact and Repair ใน Microsoft Access
  4. Backup โปรเจกต์ .e3s ก่อนแก้งานใหญ่

ก่อนเริ่ม Lab แรก ให้ E³ ใช้ Database ของผู้เรียนเองที่อยู่ในเครื่อง (ไม่ใช่ไฟล์บน Google Drive หรือ ไดรฟ์ที่แชร์) และรู้วิธี Backup Database กับโปรเจกต์ .e3s ไว้ก่อนลงมือ

ภาพรวม: Database ของตัวเอง + Backup

ลำดับหัวข้อทำอะไร
01Copy .mdbไปโฟลเดอร์งานบนเครื่อง ตั้งชื่อของตัวเอง
02Configure Databasesคลิกขวา root ของ Component tree
03Add + Data LinkAccess Database Engine 16.0 + Test Connection
04Select DatabaseComponent / Symbol / Configuration
05ตรวจ Component treeTraining_Student01 + General 9 ตัว
06Backup .mdbปิด E3 ก่อน · ไม่มี .ldb ค้าง
07Compact and RepairMicrosoft Access → Database Tools
08ตรวจหลัง Compactเปิด E3 แล้ว Component ครบ
09Backup โปรเจกต์Save As + Auto backup ทุก n นาที
สิ่งที่ต้องมี: ไฟล์ DB_MotorControl_Lab01_04.mdb (จากผู้สอน) · E3.series 2027 · Microsoft Access (สำหรับ Compact) · โฟลเดอร์งาน C:\E3_Training\

1 ไฟล์ Component + Symbol + Configuration อยู่ใน .mdb เดียว

เป้าหมาย: E3 ใช้ Database ของตัวเอง และมี Backup

  1. 1root ของ Component tree = Training_Student01
  2. 2General: Contactor, Lamp, Motor, Overload relay, Push Button, Terminal …
  3. 3ไฟล์ Backup มีวันที่ในชื่อ E3_DB_Student01_2026-11-15.mdb
ทำไมต้องมี: แลปหลัง ๆ จะสร้าง Component เอง ถ้าทุกคนแก้ไฟล์ต้นฉบับพร้อมกันจะชนกัน และแก้ผิดแล้วย้อนไม่ได้

ขั้นที่ 1: Copy Database ไปโฟลเดอร์งานของตัวเอง

  1. 1ปิด E3 ทุกหน้าต่าง แล้วสร้างโฟลเดอร์ C:\E3_Training\DB\ และ Backup\
  2. 2Copy DB_MotorControl_Lab01_04.mdb มาวาง แล้วเปลี่ยนชื่อเป็น E3_DB_<ชื่อ>.mdb
  3. 3ตัวอย่างนี้ใช้ชื่อ E3_DB_Student01.mdb
ห้ามวางบน Google Drive / OneDrive: ตอน E3 เปิด Database จะมีไฟล์ล็อก .ldb การ sync จะชนกับไฟล์นี้ ให้ใช้ไดรฟ์ในเครื่อง

ขั้นที่ 2: คลิกขวา root ของ Component tree → Configure Databases

  1. 1แท็บ Component คลิกขวาที่ root (ชื่อ Database ที่ใช้อยู่)
  2. 2Configure Databases...
  3. 3รายการ Database ที่ลงทะเบียนไว้ → กด Add...
2 เมนูที่ใช้คู่กัน: Configure Databases = ลงทะเบียนไฟล์ · Select Database = เลือกว่าจะใช้ไฟล์ไหน

ขั้นที่ 2 (ต่อ): Data Link → Access Database Engine 16.0

  1. 1แท็บ Provider: Microsoft Office 16.0 Access Database Engine OLE DB Provider
  2. 2Next >>
  3. 3Data Source: C:\E3_Training\DB\E3_DB_Student01.mdb
  4. 4Test Connection → Test connection succeeded → OK แล้ว OK
User name: ไฟล์ .mdb ของคอร์สไม่มีรหัสผ่าน ปล่อย Admin + Blank password ตามค่าเดิม

ขั้นที่ 2 (ต่อ): ตั้งชื่อ Description แล้ว Finish

  1. 1Description: Training_<ชื่อ> (ชื่อที่จะเห็นใน E3)
  2. 2Next >
  3. 3Summary: Database content = Components, Symbols, Configuration
  4. 4Finish
ไฟล์เดียวครบ: E3 อ่านตารางในไฟล์แล้วรู้เองว่ามีทั้ง Component, Symbol และ Configuration

ขั้นที่ 3: Select Database เลือก Training_Student01

  1. 1ไฟล์ใหม่อยู่ในรายการแล้ว
  2. 2OK
  3. 3คลิกขวา root อีกครั้ง → Select Database... → เปิดรายการ Component
  4. 4เลือก Training_Student01
Symbol / Configuration: E3 เปลี่ยนให้อัตโนมัติเป็นไฟล์เดียวกัน ตรวจให้ครบ 3 ช่องก่อนกด OK

ขั้นที่ 3 (ต่อ): ตรวจผลใน Component tree

  1. 1Component / Symbol / Configuration = Training_Student01
  2. 2OK
  3. 3root ของ tree เปลี่ยนทันที ไม่ต้องเปิด E3 ใหม่
  4. 4General มี 9 Component
E3 จำค่า: ค่า Database ที่เลือกบันทึกไว้ เปิด E3 ครั้งต่อไปใช้ไฟล์นี้ต่อ

ขั้นที่ 4: Backup Database (ปิด E3 ก่อน)

  1. 1E3 เปิดอยู่ = มีไฟล์ .ldb (Record-Locking) อย่า copy ตอนนี้
  2. 2ปิด E3 → ไฟล์ .ldb หายไป
  3. 3Copy ไป Backup\ ตั้งชื่อ <ชื่อเดิม>_YYYY-MM-DD.mdb
ย้อนกลับ: ปิด E3 → copy ไฟล์ Backup ทับไฟล์เดิม · หรือลงทะเบียนไฟล์ Backup แล้ว Select Database ไปที่ไฟล์นั้น

ขั้นที่ 5: Compact and Repair ใน Microsoft Access

  1. 1ปิด E3 → ดับเบิลคลิก .mdb เปิดใน Access → แท็บ Database Tools
  2. 2Compact and Repair Database (Access ทำกับไฟล์ที่เปิดอยู่ แล้วเปิดใหม่ให้)
  3. 3ปิด Access → ขนาดไฟล์ 8,964 KB → 5,816 KB
ทำเมื่อ: ไฟล์โตผิดปกติหลังแก้ Component / Symbol บ่อย ๆ, E3 เปิด Database ช้า หรือขึ้นว่าไฟล์เสีย · Backup ก่อนเสมอ

ขั้นที่ 5 (ต่อ): เปิด E3 ตรวจหลัง Compact

  1. 1root ยังเป็น Training_Student01 (ไม่ต้องตั้งค่าใหม่)
  2. 2General มี Component ครบ 9 ตัว
  3. 3ถ้าผิดปกติ: ปิด E3 แล้วเอาไฟล์ Backup กลับมา
ชื่อไฟล์เดิม: Compact แบบนี้ได้ไฟล์ชื่อเดิม ค่าใน E3 จึงใช้ต่อได้เลย

ขั้นที่ 6: Backup โปรเจกต์ .e3s

  1. 1Tools → Settings... (ต้องเปิดโปรเจกต์อยู่) → General
  2. 2Automatically generate backup file after ☑
  3. 3ตั้งเวลา เช่น 10 minutes → OK
  4. 4เริ่มแลปใหม่ทุกครั้ง: File → Save As (Lab03 → Lab04) = เก็บไฟล์แลปก่อนไว้
2 ชั้น: Auto backup กันงานหายระหว่างทำ · Save As ทุกแลปทำให้ย้อนกลับไปแลปก่อนได้

ข้อควรระวัง และวิธีแก้

อาการ / กรณีวิธีแก้
หาเมนูตั้งค่า Database ไม่เจอคลิกขวา root ของ Component tree → Configure / Select Database
Test Connection ไม่ผ่านตรวจ path และเลือก Provider Access Database Engine 16.0
มีไฟล์ .ldb ค้างE3 / Database Editor / Access ยังเปิดอยู่ ปิดให้หมดก่อน copy หรือ Compact
Database บน Google Drive / OneDriveย้ายไปไดรฟ์ในเครื่อง (C:\E3_Training\DB\)
Compact แล้ว E3 เปิดไม่ได้ปิด E3 แล้ว copy ไฟล์ Backup กลับมา
ต้องการกลับไปใช้ Database ของผู้สอนSelect Database เลือกไฟล์เดิม (รายการยังอยู่)
