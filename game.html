เกม Motor Control Lab

เกมต่อวงจรควบคุมมอเตอร์ 10 ด่าน ใช้เป็นแบบทดสอบก่อนเข้า Lab: ลากอุปกรณ์ลงแผง ต่อสาย แล้วกดทดสอบว่าวงจรทำงานตามโจทย์หรือไม่ — แต่ละ Lab ใน E³ คือวงจรของด่านนั้น

▶ เล่นในเบราว์เซอร์   ⬇ ดาวน์โหลดสำหรับ Windows (.zip)

เล่นในเบราว์เซอร์: เปิดได้ทั้ง Chrome และ Edge บนคอมพิวเตอร์ ดาว คะแนน และวงจรที่ต่อไว้ เก็บไว้ในเบราว์เซอร์ของเครื่องนั้น ถ้าจะเริ่มใหม่ให้กดปุ่ม "ล้างความคืบหน้า" ในหน้าแรกของเกม
ไฟล์สำหรับ Windows: แตกไฟล์ zip ก่อน แล้วดับเบิลคลิก MotorControlLab.exe (Windows 10/11 64 บิต ไม่ต้องติดตั้ง และไม่ต้องต่ออินเทอร์เน็ต) ครั้งแรก Windows อาจขึ้นหน้าต่าง "Windows protected your PC" เพราะไฟล์ไม่ได้ลงลายเซ็นดิจิทัล ให้กด More info แล้วกด Run anyway — ถ้าเครื่องไหนเปิด exe ไม่ได้ ให้เปิด MotorControlLab.html ในโฟลเดอร์เดียวกันแทน

ด่านในเกม และ Lab ที่คู่กัน

ด่านชื่อด่าน / สถานที่โจทย์Lab ใน E³
1ไฟดวงแรก
ห้องเก็บอะไหล่		เปิดสวิตช์แล้วหลอดไฟติด ปิดสวิตช์แล้วหลอดไฟดับLab 01
2มอเตอร์ตัวแรก
สายพานลำเลียง ไลน์บรรจุ		กด START ค้าง มอเตอร์หมุนเดินหน้า ปล่อยแล้วหยุดLab 02
3กดครั้งเดียวค้าง
ปั๊มน้ำหล่อเย็น		กด START แล้วปล่อย มอเตอร์ยังหมุนค้าง กด STOP แล้วหยุดLab 03
4กันมอเตอร์ไหม้
พัดลมระบายอากาศ		START/STOP เดินค้าง OL ทริปแล้วมอเตอร์หยุด ไฟเขียวตอนทำงาน ไฟแดงตอน OL ทริปLab 04
5เดินทีละนิด
เครื่องตัดแผ่นเหล็ก		START เดินค้าง STOP หยุด JOG เดินเฉพาะตอนกดค้างLab 05
6สั่งได้สองจุด
ลิฟต์ขนของ		START ตัวไหนก็เดินค้างได้ STOP ตัวไหนก็หยุดได้—
7เดินหน้า-ถอยหลัง
ประตูม้วนคลังสินค้า		FWD เดินหน้าค้าง REV ถอยหลังค้าง กดสลับขณะหมุนต้องไม่ลัดวงจรLab 06
8ตู้ที่มีปัญหา
ตู้ปั๊มน้ำทิ้ง งานซ่อม		ซ่อมจนกด START แล้วมอเตอร์เดินหน้าค้าง กด STOP แล้วหยุด—
9เดินตามลำดับ
สายพานสองตอน		START แล้ว M1 เดินทันที M2 เดินตามเมื่อครบ 3 วินาที STOP หยุดทั้งคู่—
10สตาร์-เดลต้า
ปั๊มน้ำดิบขนาดใหญ่		START ออกตัวแบบสตาร์ ครบ 3 วินาทีสลับเป็นเดลต้า STOP หยุด—

ด่าน 6 และ 8–10 ยังไม่มี Lab ใน E³ — เล่นในเกมเพื่อฝึกอ่านวงจรได้เลย
