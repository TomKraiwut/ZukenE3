Basic: เริ่มต้นใช้งาน E3.series

พื้นฐานที่ต้องรู้ก่อนสร้างวงจรไฟฟ้าแรกของคุณ

1. หน้าตาโปรแกรม (User Interface)

เมื่อเปิดโปรแกรมและสร้างโปรเจกต์ใหม่ จะเจอส่วนหลักๆ ดังนี้

ส่วนประกอบหน้าที่
Graphical Editorพื้นที่วาดชีท (Sheet) วงจรไฟฟ้า วาง Symbol และลาก Wire เชื่อมต่อกันที่นี่
Navigatorโครงสร้างโปรเจกต์แบบ Tree แสดงชีททั้งหมด, Device, Cable, Connector
Symbol Library / Parts Browserคลัง Symbol และฐานข้อมูลชิ้นส่วน (Component Database) ที่ลากมาวางในชีทได้
Cross-Reference / Wire Listรายงานอัตโนมัติที่รวบรวมการเชื่อมต่อและตำแหน่งอ้างอิงของ Symbol แต่ละตัว

2. Object พื้นฐานที่ใช้บ่อย

Objectใช้ทำอะไร
Symbolสัญลักษณ์กราฟิกแทนอุปกรณ์ไฟฟ้า เช่น สวิตช์ รีเลย์ หลอดไฟ วางบนชีทแล้วเชื่อมต่อกัน
Wireเส้นเชื่อมต่อทางไฟฟ้าระหว่างขา (Pin) ของ Symbol สองตัว
Connectorอุปกรณ์หลายขาที่รวมสายไฟหลายเส้นเข้าด้วยกัน เช่น ปลั๊กหรือขั้วต่อ
Cable / Bundleกลุ่มของ Wire ที่เดินรวมกันเป็นเส้นทางเดียวในความเป็นจริง (สายเคเบิลหรือมัดสายไฟ)
Component Databaseฐานข้อมูลกลางเก็บเลขที่ชิ้นส่วนจริง (Part Number) ของผู้ผลิต ผูกกับ Symbol เพื่อให้ BOM ถูกต้อง
Cross-Referenceระบบอ้างอิงอัตโนมัติที่เชื่อมโยง Symbol ตัวเดียวกันที่ปรากฏหลายชีท (เช่น ขดรีเลย์กับหน้าสัมผัส)

3. สร้างวงจรแรก: สวิตช์ควบคุมหลอดไฟ

ทำตามขั้นตอนนี้เพื่อสร้างวงจรง่ายๆ แหล่งจ่ายไฟ → สวิตช์ → หลอดไฟ

  1. สร้างโปรเจกต์ใหม่ แล้วเลือก Sheet Template ที่ต้องการ (เช่น A3 Landscape)
  2. เปิด Symbol Library ลาก Symbol แหล่งจ่ายไฟ, สวิตช์, และหลอดไฟ มาวางบนชีท
  3. ลาก Wire เชื่อมขาของแต่ละ Symbol เรียงต่อกันเป็นวงจร
  4. ดับเบิลคลิกแต่ละ Symbol แล้วเลือก Part Number จริงจาก Component Database
  5. สั่ง Generate Wire Number/Label อัตโนมัติจากเมนู Wiring
  6. รันคำสั่ง Check Design เพื่อตรวจสอบความถูกต้องของวงจรก่อนออกแบบจริง
Tip: ถ้า Symbol ไม่มี Part Number ผูกไว้ รายงาน BOM/Wire List จะไม่สมบูรณ์ — ควรผูก Component Database ให้ครบทุก Symbol ตั้งแต่ขั้นตอนออกแบบ ไม่ใช่ค่อยมาเติมทีหลัง

4. ดูผลลัพธ์เบื้องต้น

หลังวาดวงจรเสร็จ ตรวจสอบผลได้จาก:

  • BOM (Bill of Materials) — รายการชิ้นส่วนทั้งหมดพร้อมจำนวนและ Part Number
  • Wire List — รายการสายไฟทั้งหมดพร้อมจุดต้นทาง-ปลายทาง
  • Cross-Reference Report — ตำแหน่งอ้างอิงของ Symbol ที่ปรากฏซ้ำในหลายชีท
ข้อควรระวัง: ต้องรัน Check Design (การตรวจสอบความสมบูรณ์ของวงจร) ทุกครั้งก่อน Generate รายงานหรือส่งออกไฟล์ ไม่งั้นอาจได้ BOM/Harness ที่ไม่ตรงกับวงจรจริง
