Advanced: บริหาร Component Database และออกแบบ Cable/Harness

E3.series ไม่มีภาษาสคริปต์สำหรับ "ควบคุมพฤติกรรม" แบบ Plant Simulation หรือ NX MCD เพราะไม่ใช่ซอฟต์แวร์จำลองพฤติกรรม — งานขั้นสูงของ E3.series คือการบริหารจัดการ Library/Component Database ให้เป็นระบบ และออกแบบ Harness ให้นำกลับมาใช้ซ้ำได้

1. Component Database: หัวใจของความถูกต้องของแบบ

ทุก Symbol ควรผูกกับ Part Number จริงใน Component Database ที่มีข้อมูลครบ เช่น ผู้ผลิต, เบอร์ขา (Pin), พิกัดกระแส/แรงดัน เมื่อ Database เป็นกลาง (Shared Database) ทั้งทีมจะใช้ชิ้นส่วนชุดเดียวกัน ลดปัญหาแบบแต่ละคนใช้ Part Number ไม่ตรงกัน

  1. เปิด Database Manager จากเมนู Options/Database
  2. สร้าง Part ใหม่ กำหนด Manufacturer, Part Number, จำนวนขา และ Symbol ที่ใช้แทน
  3. กำหนดคุณสมบัติทางไฟฟ้า เช่น พิกัดกระแสสูงสุด สำหรับใช้ตรวจสอบ Cross-Section ภายหลัง
  4. เผยแพร่ Database กลางให้ทั้งทีมเชื่อมต่อใช้งานร่วมกัน (Shared/Network Database)
ก่อนเริ่ม: อย่าสร้าง Part ใหม่ซ้ำกับที่มีอยู่แล้วในฐานข้อมูล — ค้นหาก่อนเสมอ (Search by Manufacturer/PN) เพื่อไม่ให้เกิด Part ซ้ำซ้อนหลายรายการที่จริงๆ คือชิ้นเดียวกัน

2. ออกแบบ Cable และ Wiring Harness

เมื่อวงจร Schematic เสร็จแล้ว ใช้โมดูล Cable/Harness Design จัดกลุ่ม Wire ที่เดินเส้นทางเดียวกันในโลกจริง เป็น Bundle เดียว พร้อมคำนวณเส้นผ่านศูนย์กลางมัดสาย (Cross-Section) และสร้างแบบ Formboard สำหรับขึ้นรูปสาย 1:1

  • Cable — กำหนดจำนวนแกนสาย (Core) และมาตรฐานสายที่ใช้จริง
  • Bundle — กลุ่มสายที่เดินร่วมเส้นทางเดียวกัน คำนวณเส้นผ่านศูนย์กลางรวมอัตโนมัติ
  • Formboard — แบบ Layout สาย 1:1 ใช้ในกระบวนการผลิต Harness จริง

3. Reuse วงจรด้วย Block/Macro Symbol

รวมชุด Symbol ที่ใช้งานร่วมกันบ่อย (เช่น วงจรควบคุมมอเตอร์มาตรฐาน) เป็น Block Symbol เดียว แล้วเก็บใน Library กลาง เพื่อดึงมาวางซ้ำในหลายโปรเจกต์ โดยไม่ต้องวาด Symbol ทีละตัวใหม่ทุกครั้ง

4. ออโตเมชันด้วย E3 API/Macro

E3.series มี COM API (E3.Application) ให้เขียน Macro อัตโนมัติงานที่ทำซ้ำๆ เช่น ดึงรายชื่อ Symbol ทั้งหมดในโปรเจกต์ เพื่อตรวจสอบว่าผูก Part Number ครบทุกตัวหรือไม่ 

' ตัวอย่าง Macro (VBA-like) ตรวจสอบ Symbol ที่ยังไม่ผูก Part Number
Dim e3 As Object
Dim job As Object
Dim sym As Object
Dim symbols() As Long
Dim i As Integer

Set e3 = GetObject(, "CT.Application")
Set job = e3.CreateJobObject
job.GetAllSymbolIds symbols

For i = 0 To UBound(symbols)
    Set sym = e3.CreateSymbolObject
    sym.SetId symbols(i)
    If sym.GetPartId() = 0 Then
        Debug.Print "Missing part: " & sym.GetName()
    End If
Next i
Tip: ตั้งชื่อ Sheet, Wire Label และ Cable ให้เป็นระบบเดียวกันทั้งโปรเจกต์ (เช่น กำหนด Naming Convention ตั้งแต่ต้น) เพราะเมื่อโปรเจกต์มีหลายร้อยชีท การไล่หา Cross-Reference จะยากมากถ้าตั้งชื่อไม่เป็นระบบ
