Zuken E3 Tutorial

00. หน้าจอและพื้นฐาน

วัตถุประสงค์การเรียนรู้

  1. เปิดโปรเจกต์ .e3s และบอกหน้าที่ของหน้าจอหลักทั้ง 5 ส่วนได้
  2. อธิบายความต่างของ Component · Symbol · Device · Model และอ่านชื่ออุปกรณ์แบบ =A1 +S1.MP -Q4 ได้
  3. ค้นหา Component ใน Database Window จัด Tree Structure และตั้งช่องค้นหาเอง
  4. ตั้งค่า Settings / Grid ใช้ซูม เมาส์ และเมนูคลิกขวาได้คล่อง
  5. วางอุปกรณ์ตัวแรกจาก Component แล้วบันทึก / คืนหน้าจอด้วย Workspace Configurations

รู้จักหน้าจอ E³.series ก่อนเริ่มเขียนแบบ — ทีละขั้น รวม 13 ขั้น บนโปรเจกต์ตัวอย่าง Cooling water pump ตั้งแต่เปิดไฟล์ ค้นหา Component ตั้งค่า Grid จนวางอุปกรณ์ตัวแรก ใช้เวลาประมาณ 1 ชั่วโมง

ภาพรวม: รู้จักหน้าจอ E³ ก่อนเริ่มเขียนแบบ

ลำดับหัวข้อทำอะไร
01เปิดโปรเจกต์File → Open ไฟล์ .e3s
02หน้าจอ 5 ส่วนProject · Database · พื้นที่ทำงาน · Output · Preview
03Databaseค้นหา Component และดู Preview
04ตั้งค่าและ GridTools → Settings
05เมาส์และเมนูคลิกขวาเลือก ซูม Context menu
06วางอุปกรณ์ตัวแรกComponent → Device
สิ่งที่ต้องมี: E³.series · โปรเจกต์ตัวอย่าง Cooling water pump.e3s · เมาส์ 3 ปุ่มมีลูกกลิ้ง
ไฟล์ฝึก: คัดลอก Cooling water pump.e3s จาก C:\Users\Public\Documents\Zuken\E3.series_<เวอร์ชัน>\data\Pumpe มาไว้ในโฟลเดอร์ของตัวเองก่อนเปิด (ตั้งชื่อเป็น Cooling water pump_00.e3s) จะได้ไม่แก้ไฟล์ตัวอย่างต้นฉบับ

E³.series คืออะไร: หลายโมดูล ใช้ข้อมูลชุดเดียวกัน

โมดูลใช้ทำอะไร
E³.schematicเขียนวงจรไฟฟ้า ไฮดรอลิก นิวแมติก (บทที่ 01)
E³.panelวางอุปกรณ์ในตู้ เดินสายในราง ดูตู้แบบ 3D (บทที่ 02)
E³.cableสายเคเบิล ขั้วต่อ (Connector) และการเดินสายระหว่างอุปกรณ์
E³.formboardแบบชุดสายไฟสเกล 1:1 สำหรับโต๊ะประกอบ harness
E³.topologyกระจายอุปกรณ์ตามตำแหน่งจริง สร้าง harness อัตโนมัติ
E³.view / viewplusโปรแกรมเปิดดูแบบ ใช้ฟรี (viewplus สลับภาษา / Level ได้)
E³.enterpriseหลายคนทำงานในโปรเจกต์เดียวกันพร้อมกัน (เก็บใน SQL Server / Oracle)

ทุกโมดูลใช้ข้อมูลชุดเดียวกัน แก้ที่หนึ่ง ทุกมุมมองเปลี่ยนตามทันที

แนวคิดสำคัญ: Component · Symbol · Device · Model

คำคืออะไรตัวอย่าง
Componentอุปกรณ์จริงที่เก็บใน Database มี Part number ผู้ผลิต และรายการ Symbol ของมัน3RT10152AP02 (Contactor)
Symbolภาพกราฟิกในวงจรของอุปกรณ์หรือบางส่วนของมัน เช่น คอยล์ หรือชุดหน้าสัมผัสZUK07-50-18, S00305
DeviceComponent ที่ถูกนำมาใช้ในโปรเจกต์แล้ว ได้ชื่ออุปกรณ์ที่ไม่ซ้ำกัน-Q4 =A1 +S1.MP
Modelภาพของอุปกรณ์บนแบบตู้ (E³.panel) ตามขนาดจริงใช้ในบทที่ 02 และสร้างเองในบทที่ 04

ชื่ออุปกรณ์ (Item designation ตาม IEC 81346)

ส่วนตัวอย่างความหมาย
==A1Higher Level Assignment — ระบบ / หน้าที่
++S1.MPLocation — ตำแหน่งติดตั้ง
--Q4Device designation — ชนิด + ลำดับ
::A1Pin — ชื่อขา
ข้อมูลชุดเดียว หลายมุมมอง: อุปกรณ์ตัวเดียวกันอยู่ทั้งในวงจร Terminal Plan รายการ และแบบตู้ แก้ชื่อที่ใดก็เปลี่ยนทุกที่ทันที

ขั้นที่ 1: เปิดโปรเจกต์

  1. 1คลิกเมนู File
  2. 2Open... (Ctrl+O)
  3. 3เลือกไฟล์ Cooling water pump_00.e3s
  4. 4กด Open
หมายเหตุ: 1 โปรเจกต์ = 1 ไฟล์ .e3s เก็บทุก Sheet และเอกสารแนบไว้ในไฟล์เดียว · โปรเจกต์ใหม่ใช้ File → New (Ctrl+N)

ขั้นที่ 2: หน้าจอหลัก 5 ส่วน

  1. 1Project Window Sheet และอุปกรณ์ทั้งหมดแบบ tree
  2. 2Database Window Component / Symbol จากฐานข้อมูล
  3. 3พื้นที่ทำงาน แผ่นงาน (Sheet) ที่เปิดอยู่
  4. 4Output Window แท็บ Messages และ Results (ผลค้นหา)
  5. 5Preview ภาพตัวอย่างของสิ่งที่เลือก
ข้อควรจำ: ปิดหน้าต่างไปโดยไม่ตั้งใจ เปิดคืนได้ที่เมนู View

ขั้นที่ 3: Project Window — แท็บ Sheet และ Devices

  1. 1แท็บด้านล่างสลับมุมมอง Sheet / Devices / Panel / Variants
  2. 2ติ๊กช่องหน้าชื่อ Sheet เพื่อ เปิด / ปิด แผ่น
  3. 3Devices อุปกรณ์ทั้งหมด จัดกลุ่มตามตัวอักษร -K, -M, -Q …
  4. 4Placement Sheet / ช่องที่วาง ไอคอนน้ำเงิน = วางแล้ว
ข้อควรจำ: Page Up / Page Down = แผ่นถัดไป / ก่อนหน้า · Home / End = แผ่นแรก / สุดท้าย

ขั้นที่ 4: ค้นหา Component ใน Database และดู Preview

  1. 1พิมพ์ในช่อง Component name แล้วกด Enter (ใช้ * แทนตัวอักษรใดก็ได้)
  2. 2คลิก Component ที่พบใน tree
  3. 3Preview แสดง Symbol ของ Component
  4. 4Status bar แสดงคำอธิบายของ Component
หมายเหตุ: แท็บล่างของ Database Window: Component / Symbol / Misc · กด Reset search เพื่อล้างคำค้น

ขั้นที่ 5: จัดโครงสร้าง Database (Tree Structure)

  1. 1คลิกขวาที่ ชื่อ Database (บรรทัดบนสุดของ tree)
  2. 2เลือก Tree Structure
  3. 3Use Structure เลือก Class-main+Class english
  4. 4ตาราง Order by แสดงระดับของ tree แล้วกด OK
ทำซ้ำ: แท็บ Symbol ใช้วิธีเดียวกัน เลือกแบบ Schematictype+Class_english

ขั้นที่ 6: ตั้งช่องค้นหา (Component Search Configuration)

  1. 1ซ้าย: Attribute ทั้งหมดที่ใช้ค้นหาได้
  2. 2เลือก Attribute แล้วกดลูกศร → ย้ายไปฝั่งขวา
  3. 3ขวา: ช่องค้นหาที่จะแสดงบน Database Window
  4. 4กด OK
หมายเหตุ: เปิดได้จากคลิกขวาที่ชื่อ Database → Component Search Configuration · ค่าเริ่มต้นมีช่อง Component name, Description, Supplier ให้แล้ว

ขั้นที่ 7: ตารางและหน้าต่าง Properties (เมนู View)

  1. 1View → Properties เปิดหน้าต่าง Properties
  2. 2Device / Sheet / Pin / Connection / Cabling / Terminal Table ตารางรายการ
  3. 3คลิกอุปกรณ์บนแผ่น ชื่อเต็มขึ้นด้านบน เช่น -M1 =A1 +Tank1
  4. 4แก้ค่าในช่องแล้วกด Apply

ขั้นที่ 8: เมนู Settings และ Grid

  1. 1Tools → Settings (คีย์ S) ใช้ได้เมื่อเปิดโปรเจกต์อยู่
  2. 2Categories เลือกหมวดด้านซ้าย
  3. 3Working Grid grid ที่ใช้วางจริง (4 mm)
  4. 4Alternative Grid ใช้เมื่อกด Ctrl ค้าง
  5. 5Measurement Units Millimetres / Inches

ขั้นที่ 9: ซูม Grid ไม้บรรทัด และ Crosshairs

  1. 1ซูม Z = ลากกรอบ · O = ทั้งแผ่น · Ctrl + ลูกกลิ้ง
  2. 2Grid แสดง / ซ่อนจุด grid
  3. 3Rulers ไม้บรรทัดขอบแผ่น (View → Rulers)
  4. 4Crosshairs เส้นเล็งตามเมาส์ (View → Crosshairs)
ข้อควรจำ: ลูกกลิ้ง = เลื่อนขึ้นลง · Shift + ลูกกลิ้ง = เลื่อนซ้ายขวา · J = ซูมไปที่วัตถุที่เลือก

ขั้นที่ 10: เมาส์และเมนูคลิกขวา (Context menu)

  1. 1ซ้าย คลิก = เลือก · ลากกรอบ = เลือกหลายชิ้น (Shift + คลิก เพิ่ม/ลด)
  2. 2Device Properties แก้ทั้งอุปกรณ์ (ทุก Symbol)
  3. 3Symbol Properties แก้เฉพาะ Symbol ที่เลือก
  4. 4ระวัง ลากกรอบต้องเริ่มบนที่ว่าง ถ้าเริ่มบน Symbol จะเป็นการย้าย

ขั้นที่ 11: วางอุปกรณ์ตัวแรก (Component → Device)

  1. 1ค้นหา 3RT10152AP02 แล้วคลิกขวาที่ Component
  2. 2Place (คีย์ D) แล้วคลิกบนแผ่นตรงที่ต้องการ
  3. 3ได้ Symbol ตัวแรก ระบบตั้งชื่อ -Q1 ให้เอง
  4. 4น้ำเงิน วางแล้ว (/52.B4 = Sheet 52 ช่อง B4)
  5. 5เหลือง คอยล์และหน้าสัมผัสที่ยังไม่วาง

ขั้นที่ 12: Toolbar และการปรับแต่ง (Tools → Customise)

  1. 1Tools → Customise แท็บ Toolbars
  2. 2ติ๊กเพื่อแสดง / ซ่อน Toolbar
  3. 3Reset / Reset All คืน Toolbar เป็นค่าเดิม
  4. 4Keyboard ตั้งคีย์ลัดเอง · Application Look = สีหน้าจอ
ข้อควรจำ: คลิกขวาบนแถบ Toolbar ก็แสดง/ซ่อนได้ · ทุกคำสั่งบน Toolbar อยู่ในเมนูหลักด้วย

ขั้นที่ 13: บันทึก / คืนหน้าจอ (Workspace Configurations)

  1. 1รายการชุดหน้าจอที่บันทึกไว้
  2. 2ติ๊ก = บันทึกหน้าจอเองทุกครั้งที่ปิดโปรแกรม
  3. 3Save บันทึกหน้าจอปัจจุบัน
  4. 4Restore คืนหน้าจอตามที่บันทึกไว้
หมายเหตุ: เปิดได้ที่ View → Workspace Configurations · เก็บเป็นไฟล์ XML ใน %USERPROFILE%\AppData\Roaming\Zuken\E3.series\<Version>

ครบทุกข้อ: ไปต่อบทที่ 01: เขียนวงจรด้วย E³.schematic (Sheet, Subcircuit, ลากสาย, Terminal Plan)

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
หน้าต่าง Project / Database / Messages หายไปView → Project / Database / Output Windows หรือ Workspace Configurations → Restore
Tools → Settings กดไม่ได้ต้องเปิดโปรเจกต์ก่อน เมนู Settings ใช้ได้เมื่อมีโปรเจกต์เปิดอยู่
ลากกรอบแล้ว Symbol ขยับเริ่มลากจากพื้นที่ว่างบนแผ่น · ย้ายผิดกด Ctrl+Z
ค้นหา Component ไม่เจอใช้ * แทนตัวอักษรใดก็ได้ เช่น 3RT1015* แล้วกด Enter · กด Reset search ล้างคำค้น
ลบ Symbol แล้วอุปกรณ์ยังอยู่ใน Device tree (สีเหลือง)ปกติ: Delete เอาออกจากแผ่นเท่านั้น ลบออกจากโปรเจกต์ใช้ Delete Forced ใน Device tree
ซูมแล้วหาแผ่นไม่เจอกด O (Fit to Window) เพื่อดูทั้งแผ่น
