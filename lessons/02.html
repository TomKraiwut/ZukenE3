02. ออกแบบตู้ E³.panel

วัตถุประสงค์การเรียนรู้

  1. เปิดแบบตู้ และบอกได้ว่า Mounting rail / Cable duct / พื้นที่สีแดงคืออะไร
  2. หาอุปกรณ์ที่ยังไม่วางในแท็บ Panel - Not Placed แล้ววางลงรางที่ถูกต้อง
  3. เพิ่ม Cable Duct และราง Mount (TS 35 mm) และอธิบายหน้าที่ของ Slot description
  4. สั่ง Panel Autoconnect ให้เดินสายตามราง แล้วดูตู้แบบ 3D
  5. ส่งออก Wiring list จากแบบตู้เป็น Excel

ตู้คืออีกมุมมองของวงจรเดียวกัน — ทีละขั้น รวม 10 ขั้น ใน E³.panel วางอุปกรณ์ -Q6 ที่ได้จากปั๊มตัวที่ 3 ในบทที่ 01 ลงราง เพิ่มราง เดินสายอัตโนมัติ ดูตู้ 3D และส่งออก Wiring list ใช้เวลาประมาณ 1 ชั่วโมง

ภาพรวม: ตู้คืออีกมุมมองของวงจรเดียวกัน

ลำดับหัวข้อทำอะไร

03วางลงรางระบบไฮไลต์รางที่ติดตั้งได้
04ราง Mount / Cable DuctSlot TS 35 mm · ความจุราง
05Autoconnectเดินสายตามรางอัตโนมัติ

สิ่งที่ต้องมี: ผ่านบทที่ 01 (มี -Q6 / -Q7 จากปั๊มตัวที่ 3) · license E³.panel · เมาส์ 3 ปุ่มสำหรับหมุนมุมมอง 3D
ข้อมูลชุดเดียว: เปลี่ยนชื่ออุปกรณ์ในวงจร ชื่อในตู้เปลี่ยนตาม · อุปกรณ์ที่เพิ่มในวงจรจะรอใน Panel - Not Placed

ขั้นที่ 1: เปิดแบบตู้ Sheet 6

  1. 1พื้นที่สีแดง = ความร้อนสูญเสีย (Level 200) ปิดได้ด้วยคีย์ L
  2. 2Mounting rail รางจับอุปกรณ์ (สีเหลือง)
  3. 3Cable duct รางเดินสาย สายในตู้เดินผ่านรางนี้
หมายเหตุ: เปิด Sheet 6 จากโฟลเดอร์ 02-Panel · ซูมด้วย Ctrl + ล้อเมาส์

ขั้นที่ 2: แท็บ Panel - Placed และ Not Placed

  1. 1แท็บ Panel - Placed (ไอคอนสีเขียว)
  2. 2อุปกรณ์ที่อยู่ในตู้แล้ว
  3. 3แท็บ Panel - Not Placed (สีเหลือง)
  4. 4-Q6 / -Q7 จากปั๊มตัวที่ 3 ในบทที่ 01 รอวาง
ข้อควรจำ: อุปกรณ์ที่เพิ่มในวงจรจะไม่อยู่ในตู้เอง ต้องวางลงตู้จากแท็บ Not Placed

ขั้นที่ 3: วาง -Q6 ลงราง

  1. 1คลิกขวาที่ -Q6 (Preview แสดงรูปอุปกรณ์)
  2. 2เลือก Place
  3. 3รางที่ติดตั้งได้เป็นสีชมพู คลิกวางบนราง
ข้อควรจำ: อุปกรณ์ snap เข้าราง วางซ้อนกันหรือวางบน Cable duct ไม่ได้ · ตรวจจาก Slot Description ของราง

ขั้นที่ 4: ผลการวาง

  1. 1-Q6 อยู่บนรางแล้ว (3RT10251BB40)
  2. 2Not Placed เหลือเฉพาะ -Q7
หมายเหตุ: Status bar ล่างจอแจ้ง Component และตำแหน่งที่วาง

ขั้นที่ 5: เพิ่ม Cable Duct

  1. 1Insert → Mount... (ราง)
  2. 2Insert → Cable Duct...
  3. 3Height ความสูงราง
  4. 4Width ความกว้างราง (Quicktour ใช้ 25 mm)
  5. 5Fill limit ความจุสาย (ค่าจาก Settings 70%)
หมายเหตุ: ไม่ติ๊ก Length แล้วลากความยาวเอง · จุดวงกลมเล็กปรากฏเมื่อรางเชื่อมกัน

ขั้นที่ 6: เพิ่ม Mount (TS 35 mm)

  1. 1Slot description = TS 35 mm
  2. 2Height 7.5 mm
  3. 3Width 35 mm
ข้อควรจำ: ระบบใช้ Slot description ตรวจว่าอุปกรณ์ตัวไหนติดตั้งบนรางนี้ได้ (Model ต้องมีค่าเดียวกัน บทที่ 04)

ขั้นที่ 7: Logic Lines และ Panel Autoconnect

  1. 1View → Logic Lines
  2. 2Cores On Panel แสดงเส้นประของสายที่ต้องเดิน
  3. 3คลิกขวาที่อุปกรณ์ (หรือ Ctrl+A) → Panel Autoconnect
หมายเหตุ: ระบบหาเส้นทางสั้นที่สุดผ่าน Cable duct ตามความจุราง · สายที่เดินไม่ได้แจ้งใน Output Window → Results

ขั้นที่ 8: สลับเป็นมุมมอง 3D

  1. 1Panel toolbar → ปุ่ม 3D (แสดง Sheet แบบ 3D)
  2. 23D View toolbar → Isometric
  3. 3ตู้ทั้งแผ่นแสดงแบบ 3D
เปิด toolbar: คลิกขวาบนแถบ toolbar แล้วติ๊ก Panel และ 3D View (ค่าเริ่มต้นปิดอยู่)

ขั้นที่ 9: ดูตู้ 3D

  1. 1อุปกรณ์อยู่บนแผ่นติดตั้งในตู้ตามตำแหน่งจริง
  2. 2ลากปุ่มซ้าย หมุน · ลากปุ่มขวา เลื่อน · หมุนล้อ ซูม
  3. 3Shift + ลูกศร พับผนัง / ประตู (Pivot)
หมายเหตุ: คลิกขวาที่อุปกรณ์ → Transparency in 3D ทำให้มองทะลุได้

ขั้นที่ 10: Wiring List จากแบบตู้

  1. 1Add-ons
  2. 2EXCEL Documents
  3. 3Wiring list from Panel
ผลลัพธ์: Excel แสดง From / To เลขสาย ชนิด สี ขนาดหน้าตัด ความยาว และเส้นทางเดินสาย

Wiring list (Excel)ขั้นที่ 10 Add-ons → EXCEL Documentsรายการสาย From / To ความยาว และเส้นทาง
