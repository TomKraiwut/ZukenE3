03. สร้าง Symbol และ Component

วัตถุประสงค์การเรียนรู้

  1. เปิด Database Editor (E³.dbe) จากโปรเจกต์ และหา tree ของ Symbol / Component
  2. สร้าง Symbol คอยล์ใหม่ วาดกราฟิก วาง Node แล้วตั้ง Name / Type / Class
  3. สร้าง Component ใหม่ด้วย Component Wizard โดยตั้งต้นจากตัวที่มีอยู่ (Make new copy)
  4. ดู Component Properties และ Pin Assignment ที่ผูกเลขขากับ Symbol
  5. บอกได้ว่าเมื่อไรควร Save To Database และต้องสำรองฐานข้อมูลก่อน

Symbol + เลขขา + ข้อมูล = Component — ทีละขั้น รวม 9 ขั้น ใน Database Editor สร้าง Symbol คอยล์ G01Y001B แล้วสร้าง Component GHR15511201R003 โดยตั้งต้นจาก 3RT10151AB01 ใช้เวลาประมาณ 1.5 ชั่วโมง

ภาพรวม: Symbol + เลขขา + ข้อมูล = Component

ลำดับหัวข้อทำอะไร
01เปิด Database EditorTools → Start Database Editor
02New Symbolวาดกราฟิก วางขา (Node)
03Symbol Propertiesชื่อ Type Class
04Component Wizardตั้งต้นจาก Component เดิม
05แก้ ComponentPins · Pin Assignment
06Save To Databaseบันทึกเมื่อพร้อมเท่านั้น
สิ่งที่ต้องมี: ผ่านบทที่ 00–01 · license Database Editor · ฐานข้อมูลสำหรับฝึก (สำรองไฟล์ .mdb ก่อนเสมอ)
ระวัง: Save To Database เขียนลงฐานข้อมูลที่ใช้งานอยู่ทันที ทุกคนที่ใช้ฐานข้อมูลเดียวกันเห็นการแก้ไข ฝึกบนสำเนาฐานข้อมูลเท่านั้น

ขั้นที่ 1: เปิด Database Editor

  1. 1ในหน้าต่างโปรเจกต์ เมนู Tools
  2. 2Start Database Editor
  3. 3E³.dbe เปิดเป็นหน้าต่างใหม่ In use...
  4. 4แท็บ Comp / Symbol / Misc / Model
หมายเหตุ: E³.dbe เป็นอีกโปรแกรมหนึ่ง ปิดแล้วกลับไปที่หน้าต่างโปรเจกต์ได้เลย · ขยายหน้าต่างให้เต็มจอเพื่อให้เห็น tree

ขั้นที่ 2: สร้าง Symbol ใหม่

  1. 1แท็บ Symbol คลิกขวาที่โฟลเดอร์ใน tree
  2. 2New Symbol
  3. 3แผ่นวาด Symbol เปิดขึ้น วงกลมกากบาท คือจุด Origin
หมายเหตุ: เมนูเดียวกันมี New Component และ New Model (บทที่ 04)

ขั้นที่ 3: วาดกราฟิกและวางขา (Node)

  1. 1เลือกชนิด Node จาก list
  2. 2from top / from bottom = ทิศที่สายเข้า
  3. 3วาดสี่เหลี่ยมคอยล์ด้วยเครื่องมือ Graphic บน grid
  4. 4คลิกวาง Node ที่ขอบบน และขอบล่าง
ข้อควรจำ: ลำดับการวางขาสำคัญ ใช้จับคู่กับเลขขาของ Component · เปิด Grid ก่อนวาด

ขั้นที่ 4: Symbol Properties

  1. 1คลิกขวาที่ Symbol ใหม่ใน tree
  2. 2Properties...
  3. 3Name = G01Y001B (ตั้งตาม IEC 617)
  4. 4Type Normal
  5. 5Class = Coil
ทำซ้ำ: ตั้ง Origin และพื้นที่ของ Symbol ก่อน Save To Database · ฝั่งโปรเจกต์กด F5 ที่ Database เพื่อเห็น Symbol ใหม่

ขั้นที่ 5: New Component จากตัวที่มีอยู่

  1. 1ค้นหา 3RT10151AB01 แล้วคลิกขวา
  2. 2New Component
  3. 3Name = GHR15511201R003
  4. 4ใช้ Attribute และโครงสร้างของ 3RT10151AB01
  5. 5Standard device
หมายเหตุ: Component Wizard มี 4 หน้า: Identification → Properties → Structure → Complete

ขั้นที่ 6: Properties และ Structure

  1. 1แก้ Attribute เช่น Article number, Description, Supplier
  2. 2ติ๊ก Make new copy
  3. 3Preview แสดง Symbol / Model ในโครงสร้างเดิม
ข้อควรจำ: Make new copy ทำให้แก้โครงสร้างได้ โดยไม่กระทบ Component อื่นที่ใช้โครงสร้างเดียวกัน

ขั้นที่ 7: Complete → แก้แบบกราฟิก

  1. 1Edit component graphically
  2. 2ยังไม่เลือก Save to database
  3. 3Finish
  4. 4Symbol 1–4 ของ Component เรียงตามลำดับ
  5. 5Model สำหรับแบบตู้
ทำต่อ: กด L โหลด component-editor.vis ให้ดูง่าย แล้วลบ / เพิ่ม Symbol ตามอุปกรณ์จริง

ขั้นที่ 8: Component Properties และ Pin Assignment

  1. 1คลิกขวา Component ใน tree → Properties
  2. 2Attribute ของ Component
  3. 3แท็บ Pin Assignment Symbol ในโครงสร้าง
  4. 4ผูกชื่อขา A1/A2, 1–6, 13/14 กับ Symbol
หมายเหตุ: Order Definition กำหนดลำดับ Symbol · Master/Slave Assignment ทำให้มี Cross-reference

ขั้นที่ 9: Save To Database (เมื่อพร้อม)

  1. 1คลิกขวา Symbol / Component ใน tree → Save To Database
  2. 2ตรวจชื่อ Class เลขขา และ Model ให้ครบก่อนบันทึก
  3. 3ฝั่งโปรเจกต์กด F5 ที่ Database Window
ระวัง: บันทึกลงฐานข้อมูลที่เปิดอยู่ทันที และย้อนไม่ได้ด้วย Undo · สำรอง .mdb ก่อน และฝึกบนสำเนา

ไฟล์ที่ใช้ในบทนี้

ไฟล์มาจากไหนใช้ทำอะไร
โปรเจกต์ .e3s ที่เปิดอยู่สำเนาจากบทที่ 00–01เปิด Database Editor จาก Tools → Start Database Editor
ฐานข้อมูลสำหรับฝึก (.mdb)สำเนาของฐานข้อมูลที่ใช้งาน — สำรองไฟล์ก่อนเสมอสร้าง Symbol / Component ใหม่ (Save To Database เขียนลงไฟล์นี้)

Checklist ท้ายบท

ข้อสิ่งที่ต้องทำได้
1เปิด Database Editor และหา tree ของ Symbol ได้
2สร้าง New Symbol และวาง Node ได้
3ตั้งชื่อ / Class ใน Symbol Properties ได้
4ใช้ Component Wizard ตั้งต้นจากตัวเดิมได้
5อธิบายความต่าง Use current / Make new copy ได้
6ดู Pin Assignment ได้
7บอกได้ว่าเมื่อไรควร Save To Database
ครบทุกข้อ: ไปต่อบทที่ 04: สร้าง Model ของอุปกรณ์สำหรับแบบตู้

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
ไม่เห็น tree ของ Symbolขยายหน้าต่าง E³.dbe ให้เต็มจอ หรือลากขยายช่อง Database Window
กด New แล้วได้หน้าต่าง E³.dbe ใหม่ปิดหน้าต่างนั้น ใช้คลิกขวาใน tree → New Symbol / New Component
เมนู Insert กดไม่ได้ต้องเปิด Symbol / Model อยู่ก่อน
โปรเจกต์ไม่เห็น Symbol ใหม่Save To Database แล้วกด F5 ที่ Database Window ของโปรเจกต์
แก้ Component แล้วกระทบตัวอื่นใช้ Make new copy ใน Structure ของ Wizard
ปิด E³.dbe แล้วถามบันทึกNo = ไม่บันทึก · Save to Database = เขียนลงฐานข้อมูลจริง
