04. สร้าง Model ของตู้

วัตถุประสงค์การเรียนรู้

  1. สร้าง New Model จากแท็บ Model ใน Database Editor
  2. ตั้ง Model name / Model type และขนาด X / Y / Z ใน Model Properties
  3. ใส่ Mounting Description ให้ตรงกับ Slot description ของราง (เช่น TS 35 mm)
  4. ใช้เมนู Insert: Slot, Model View และ STEP model
  5. ปิด E³.dbe โดยไม่บันทึก และรู้ว่า Save to Database มีผลกับใครบ้าง

Model + Slot = วางลงตู้ได้ — ทีละขั้น รวม 6 ขั้น ใน Database Editor สร้างภาพของอุปกรณ์สำหรับแบบตู้ ตั้งขนาดจริงและ Mounting Description ให้อุปกรณ์ snap เข้าราง Mount ในบทที่ 02 ใช้เวลาประมาณ 45 นาที

ภาพรวม: Model + Slot = วางลงตู้ได้

ลำดับหัวข้อทำอะไร
01แท็บ Modeltree ของ Model ใน Database
02New Modelแผ่นวาด Model เปล่า
03Model Propertiesชื่อ ชนิด หน่วย
04ShapeMounting description · ขนาด X/Y/Z
05Insert Slotจุด / เส้น / พื้นที่สำหรับติดตั้ง
06ปิดโดยไม่บันทึกบันทึกจริงเมื่อพร้อม
สิ่งที่ต้องมี: ผ่านบทที่ 02–03 · license Database Editor + E³.panel · ขนาดจริงจาก datasheet ของอุปกรณ์
เชื่อมกับบทที่ 02: Mounting description ของ Model (เช่น TS 35 mm) ต้องตรงกับ Slot description ของราง Mount ในตู้

ขั้นที่ 1: New Model

  1. 1แท็บ Model
  2. 2คลิกขวาที่โฟลเดอร์ เช่น Electric
  3. 3New Model
หมายเหตุ: เปิด E³.dbe จาก Tools → Start Database Editor (บทที่ 03) แล้วขยายหน้าต่างให้เต็มจอ

ขั้นที่ 2: แผ่นวาด Model

  1. 1จุดกลางแผ่นคือ Origin ของ Model
  2. 2NewModel1 อยู่ในโฟลเดอร์ Model ของ In use...
  3. 3วาดรูปด้านหน้าด้วยเครื่องมือ Graphic หรือ Insert → STEP model
หมายเหตุ: Model ใช้หน่วยมิลลิเมตร ขนาดต้องตรงอุปกรณ์จริง เพราะใช้ตรวจการชนในตู้

ขั้นที่ 3: Model Properties

  1. 1Model name
  2. 2Model type = Device
  3. 3แท็บ Shape: Mounting Description = TS 35 mm
  4. 4เลือก / พิมพ์แล้วกด Add
  5. 5Size X / Y / Z
ข้อควรจำ: อุปกรณ์จะ snap เข้าราง Mount ที่มี Slot description ตรงกับ Mounting Description นี้

ขั้นที่ 4: เมนู Insert ของ Model

  1. 1Slot... จุดติดตั้ง
  2. 2Model View มุมมอง Back / Right / Left / Top / Bottom
  3. 3STEP model... นำเข้าไฟล์ 3D
หมายเหตุ: เมนู Insert ใช้ได้เมื่อมี Model เปิดอยู่

ขั้นที่ 5: Insert Slot

  1. 1Type ชนิด Slot
  2. 2Description เช่น Rail type 100 / TS 35 mm
  3. 3Name ชื่อ Slot
  4. 4Point / Line / Area
หมายเหตุ: Point = จุดยึด · Line = แนวราง · Area = พื้นที่ติดตั้ง

ขั้นที่ 6: ปิด E³.dbe

  1. 1No = ไม่บันทึก (ใช้ตอนฝึก)
  2. 2Save to Database = บันทึกลงฐานข้อมูลจริง
ระวัง: Save to Database เขียนทับฐานข้อมูลที่ทุกคนใช้ร่วมกัน สำรอง .mdb ก่อนเสมอ

ไฟล์ที่ใช้ในบทนี้

ไฟล์มาจากไหนใช้ทำอะไร
ฐานข้อมูลสำหรับฝึก (.mdb)สำเนาเดียวกับบทที่ 03 — สำรองไฟล์ก่อนเสมอสร้าง Model ใหม่ในแท็บ Model (ฝึกแล้วปิดโดยไม่บันทึก)
datasheet ของอุปกรณ์ผู้ผลิตอุปกรณ์ขนาดจริง X / Y / Z และชนิดรางที่ติดตั้ง

Checklist ท้ายบท

ข้อสิ่งที่ต้องทำได้
1สร้าง New Model จากแท็บ Model ได้
2ตั้งชื่อและชนิดใน Model Properties ได้
3ใส่ Mounting Description ให้ตรงกับรางได้
4ใส่ขนาด X / Y / Z ได้
5เปิด Insert Slot และเลือกชนิดได้
6ปิด E³.dbe โดยไม่บันทึกได้
ครบทุกข้อ: ทวนบทที่ 02: วาง Component ที่มี Model ลงรางในตู้

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
ไม่เห็น tree ของ Modelขยายหน้าต่าง E³.dbe ให้เต็มจอ แล้วเลือกแท็บ Model
เมนู Insert กดไม่ได้ต้องมี Model เปิดอยู่ก่อน (ขั้นที่ 1–2)
วางอุปกรณ์ในตู้แล้วไม่ snap เข้ารางMounting Description ของ Model ต้องตรงกับ Slot description ของราง Mount (เช่น TS 35 mm)
อุปกรณ์ในตู้ขนาดไม่ตรงของจริงModel ใช้หน่วยมิลลิเมตร ใส่ Size X / Y / Z จาก datasheet
ปิด E³.dbe แล้วถามบันทึกNo = ไม่บันทึก (ตอนฝึก) · Save to Database = เขียนลงฐานข้อมูลจริงที่ทุกคนใช้
