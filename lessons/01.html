01. วงจรไฟฟ้า E³.schematic

วัตถุประสงค์การเรียนรู้

  1. เพิ่ม Sheet ใหม่พร้อม =A1 / +S1.MP และ Format แล้วใส่หัวกระดาษจาก Translation Table
  2. เปิด Device Properties ของมอเตอร์ และเปลี่ยน Component จาก list ที่ใช้กับ Symbol นั้นได้
  3. Copy / Paste วงจรปั๊ม แล้วอ่าน Messages ว่าระบบตั้งชื่ออุปกรณ์ใหม่ให้อย่างไร
  4. ค้นหาด้วย Search (F3) และ Jump ไปยังมุมมองอื่นของอุปกรณ์
  5. อธิบายว่า Terminal Plan อัปเดตตามวงจร และส่งออกแบบเป็น PDF

เขียนวงจรไฟฟ้าด้วย E³.schematic บนข้อมูลชุดเดียว — ทีละขั้น รวม 11 ขั้น เพิ่ม Sheet ผูก Component คัดลอกวงจรปั๊มตัวที่ 2 เป็นปั๊มตัวที่ 3 ค้นหา ดู Terminal Plan แล้วส่งออก PDF ใช้เวลาประมาณ 1.5 ชั่วโมง

ภาพรวม: เขียนวงจรด้วยข้อมูลชุดเดียว

ลำดับหัวข้อทำอะไร
01เพิ่ม SheetNew Sheet · หัวกระดาษจาก Translation Table

03คัดลอกวงจรCopy / Paste ชื่ออุปกรณ์ไม่ซ้ำเอง
04ค้นหาและกระโดดF3 Search · Jump ไป tree / Variant
05Terminal Planแผนขั้วต่ออัปเดตตามวงจร
06ส่งออก PDFFile → Export → PDF
สิ่งที่ต้องมี: ผ่านบทที่ 00 หน้าจอและพื้นฐาน · สำเนา Cooling water pump.e3s ของตัวเอง · license E³.schematic (Export PDF ต้องมี license)
ไฟล์ฝึก: คัดลอก Cooling water pump.e3s จาก C:\Users\Public\Documents\Zuken\E3.series_<เวอร์ชัน>\data\Pumpe มาไว้ในโฟลเดอร์ของตัวเองก่อนเปิด (เช่น Cooling water pump_01.e3s)

ขั้นที่ 1: เพิ่ม Sheet ใหม่

  1. 1คลิกขวาที่ Sheet 8 ใน Project Window
  2. 2เลือก New Sheet...
  3. 3Name = 7
  4. 4=A1 และ +S1.MP
  5. 5Format = DINA3_Electric
  6. 6Insert before แล้วกด OK
หมายเหตุ: =A1 คือ Higher level assignment (ระบบ) · +S1.MP คือ Location (ตำแหน่งติดตั้ง) ใช้กับอุปกรณ์ทุกตัวบนแผ่นนี้

ขั้นที่ 2: หัวกระดาษจาก Translation Table

  1. 1คลิกขวา Sheet 7 → Sheet Properties คลิกช่อง Entry ของ Name (1) แล้วกด ...
  2. 2พิมพ์คำค้นในแถวกรอง เช่น power supply*
  3. 3เลือก Power supply แล้วกด OK
  4. 4ทำซ้ำกับ Name (2) = main switch
ข้อควรจำ: ข้อความจาก Translation Table แปลภาษาได้อัตโนมัติ (สูงสุด 5 ภาษา) · * ใช้แทนตัวอักษรใดก็ได้

ขั้นที่ 3: ตรวจ Sheet ใหม่และหัวกระดาษ

  1. 17 =A1 +S1.MP อยู่ในโฟลเดอร์ 03-circuit diagram
  2. 2หัวกระดาษแสดง Power supply / main switch
หมายเหตุ: แก้ Sheet Properties ภายหลังได้เสมอ หัวกระดาษเปลี่ยนตามทันที

ขั้นที่ 4: Device Properties ของมอเตอร์

  1. 1คลิกขวาที่มอเตอร์ -M2 บน Sheet 9
  2. 2เลือก Device Properties...
  3. 3Device designation -M2 =A1 +Tank1
  4. 4Component = K21R-160-L8
  5. 5Function = pump 2 (ติ๊กให้แสดงบนแบบ)
ข้อควรจำ: Device = Component ที่อยู่ในโปรเจกต์แล้ว · แก้ชื่อที่นี่ ทุก Sheet และแบบตู้เปลี่ยนตาม

ขั้นที่ 5: เปลี่ยน Component (แสดงเฉพาะตัวที่ใช้ได้)

  1. 1กดลูกศรของช่อง Component
  2. 2list แสดงเฉพาะ Component ที่ใช้กับ Symbol นี้ได้ เช่น K21R-132-M4, K21R-160-M6
  3. 3เลือกแล้วกด OK (ในบทเรียนนี้กด Cancel)
ข้อดีของการทำงานแบบอิง Component: ระบบตรวจเลขขาตั้งแต่ต้น ใช้หน้าสัมผัสเกินจำนวนที่อุปกรณ์มีจริงไม่ได้

ขั้นที่ 6: เลือกวงจรปั๊ม 2 แล้ว Copy

  1. 1ลากกรอบจากมุมบนซ้ายของวงจรปั๊มตัวที่ 2
  2. 2ปล่อยที่มุมล่างขวา ชิ้นที่เลือกเป็นสีไฮไลต์
  3. 3คลิกขวาที่ชิ้นที่เลือก → Copy (Ctrl+C)
หมายเหตุ: ลากกรอบจากพื้นที่ว่าง ถ้าเริ่มบน Symbol จะกลายเป็นการย้าย Symbol

ขั้นที่ 7: Paste แล้วระบบตั้งชื่อใหม่ให้เอง

  1. 1Edit → Paste แล้วคลิกวางในที่ว่างของแผ่น
  2. 2Messages แจ้งชื่อที่เปลี่ยน เช่น -M2 → -M3, -Q4 → -Q6, -W2 → -W5
  3. 3ได้วงจรปั๊มตัวที่ 3 ที่ชื่อไม่ซ้ำ
ข้อควรจำ: E³ ไม่ยอมให้ชื่ออุปกรณ์ซ้ำในโปรเจกต์ · อุปกรณ์ใหม่ (-Q6, -Q7) จะรอวางในแบบตู้ (บทที่ 02)

ขั้นที่ 8: ค้นหาด้วย Search (F3)

  1. 1Edit → Search (F3) Type = Signal
  2. 2Value = L1
  3. 3กด OK
  4. 4ผลอยู่ในแท็บ Results คลิก [Jump] เพื่อไปยังจุดนั้น
ทำซ้ำ: Shift+F3 หรือ Edit → Reset Highlight ล้างสีไฮไลต์หลังค้นหา

ขั้นที่ 9: Jump ไปยังมุมมองอื่นของอุปกรณ์

  1. 1คลิกขวาที่อุปกรณ์ → Jump
  2. 2เลือกปลายทาง เช่น Device Tree, Device Table หรือ Variant/Option Tree
หมายเหตุ: มอเตอร์ -M2 เป็นของ Option 'Additional pump 1' ปิด Option นี้แล้วอุปกรณ์ทั้งชุดจะซ่อนทั้งวงจรและตู้

ขั้นที่ 10: Terminal Plan อัปเดตตามวงจร

  1. 1Sheet 32 ในโฟลเดอร์ 04-Terminal Plan คือแผนขั้วต่อ -XT2
  2. 2ทุกแถวคือขั้วจริง ปลายสายสองฝั่งมาจากวงจร
  3. 3สร้างแผนใหม่: Insert → Terminal Plan...
ข้อควรจำ: แก้เลขขั้วในวงจร แผนเปลี่ยนตาม · ลากเรียงขั้วในแผน วงจรเปลี่ยนตาม

ขั้นที่ 11: ส่งออก PDF

  1. 1File
  2. 2Export
  3. 3PDF...
  4. 4Export Range: All / Current sheet / Sheets
  5. 5ตั้งชื่อไฟล์แล้วกด Save
หมายเหตุ: ต้องมี license Export PDF · Cross-reference ใน PDF คลิกได้

ไฟล์ที่ใช้ในบทนี้

ไฟล์มาจากไหนใช้ทำอะไร
Cooling water pump_01.e3sสำเนาใหม่ของโปรเจกต์ตัวอย่าง data\Pumpe\Cooling water pump.e3sฝึกขั้นที่ 1–11
ไฟล์เดียวกันหลังจบบทมี Sheet 7 และวงจรปั๊มตัวที่ 3 (-M3, -Q6, -Q7 …)ใช้ต่อในบทที่ 02 (วาง -Q6 / -Q7 ลงตู้)
ไฟล์ PDFขั้นที่ 11 File → Export → PDFแบบสำหรับส่งต่อ Cross-reference คลิกได้

Checklist ท้ายบท

ข้อสิ่งที่ต้องทำได้

ครบทุกข้อ: ไปต่อบทที่ 02: วางอุปกรณ์ในตู้ด้วย E³.panel

ปัญหาที่พบบ่อย และวิธีแก้

อาการวิธีแก้
Sheet ใหม่ไปอยู่ผิดโฟลเดอร์Sheet Properties → Document Type ต้องเป็น 03-circuit diagram
ข้อความหัวกระดาษยาวเกิน 30 ตัวอักษรใช้ข้อความจาก Translation Table แทนการพิมพ์ยาว ๆ
Format ของแผ่นเปลี่ยนเป็นข้อความแปลก ๆเลือก Format ใหม่จาก list (DINA3_Electric) ก่อนกด OK
Paste แล้วได้ข้อความแทนวงจรClipboard มีข้อความจากโปรแกรมอื่น ใช้คลิกขวา → Copy ใน E³ ใหม่ แล้ว Edit → Paste
Component ที่ต้องการไม่อยู่ใน listlist แสดงเฉพาะตัวที่ใช้กับ Symbol นั้นได้ ต้องสร้าง Component ใหม่ (บทที่ 03)
ไฮไลต์จากการค้นหาไม่หายShift+F3 หรือ Edit → Reset Highlight
